# 一、MadSpace工作范围及职责

- **项目策略与定价：**根据甲方价格信息制定众筹定价及调整建议，并提交甲方书面确认。
- **页面策划与制作：**负责众筹页面的信息架构、视觉设计与制作、英文/当地语言文案撰写。
- **平台对接与上线：**对接平台、建立项目、协助审核，并争取平台营销资源。
- **广告规划与执行：**在甲方确认预算内制定预热期及众筹期广告计划，明确渠道、地区和每日预算。
- **广告创意与优化：**负责付费广告创意、文案及效果优化，并对可追踪部分按工作日更新数据。
- **邮件营销：**测试、撰写并执行众筹期间的电子邮件营销活动。
- **社媒与社群推广：**运营海外社交媒体，并对接第三方众筹社群以获得有效支持和转化。
- **KOL与公关协助：**在样品充足合格前提下梳理KOL大名单，联络并整理5-10家有评测意向的KOL及费用清单，甲方确认后安排。
- **项目运营与售前客服：**负责众筹在线期间项目相关邮件回复及售前客服配合。
- **报告交付：**上线后7个工作日内提供上线报告；众筹结束后10个工作日内提供结案报告。
- **全案运营:**包含以上所有工作
- **线下活动策划与执行:** 负责策划品牌在海外的线下发布会、街头试用、媒体会、展会等线下活动与人力支援、执行

# 二、MadSpace标准产出清单

- 众筹页面设计稿、页面成稿及页面文案；
- 平台项目后台搭建、提审材料清单及上线协同记录；
- 预热期/众筹期广告投放计划（渠道、地区、日预算）；
- 广告素材创意、广告文案及优化记录；
- 可追踪付费广告的工作日数据报表；
- 邮件营销测试方案、邮件文案与发送执行记录；
- 海外社交媒体内容及运营记录；
- 第三方众筹社群沟通与推广记录；
- KOL合作大名单、至少5-10家意向KOL名单及费用清单；
- 售前客服/项目邮件回复记录、上线报告及结案报告。

**责任边界：广告费、评测合作费、样品及寄送、产品素材/成片、生产、包装、发货与售后由甲方承担；Late Pledge / Indemand 阶段仅在甲方另行委托时继续运营。**
