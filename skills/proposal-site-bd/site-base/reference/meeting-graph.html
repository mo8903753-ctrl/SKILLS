预对接候选

点子节点时，会带出「这个小标题 + 它后面的全部内容，直到下一个小标题」。

这是什么

会议用的节点图谱导航层。开会时按 M 打开：中心是方案，外圈是章节，鼠标悬停某章展开它的子节点，点击任意节点就在图谱右侧直接展开对应内容——不跳走、不滚动，对方始终看得到自己在整个体系的哪个位置。

接进一个已有方案，只需 4 步

① 复制本文件 <style> 里 方案图谱 那段 CSS
② 复制 <body> 末尾那段 #mapBtn + #mapOv 标记
③ 复制 <script> 里的 IIFE
④ 只改 NODES 数组，把 target 指到你页面里的 id

NODES 字段

{id:'s-rich', label:'Rich $560K', r:16, g:2, p:'c07', target:'#n-budget', bud:'R'}

id      唯一标识
label   节点显示名（根节点可用 \n 换行）
r       半径：章节 24-28 / 子节点 14-17 / 根节点会自动撑大
g       配色组 0根 1判断与市场 2钱与转化 3执行与节奏 4风险与边界
p       父章节 id（有 p 就是子节点，默认收起）
target  CSS 选择器，指向正文里要展开的元素
bud/dur 可选：点击时先把正文的预算/档期切换器切到该版本，再克隆

为什么内容是克隆的

面板内容用 cloneNode 从正文取，不另写一份——避免同一个数字有两处出处、改一处忘另一处。克隆时会剥掉 id 防重复，并把预算/档期切换器重新接线，所以面板里的切换器能独立工作（对方追问「加预算什么样」，当场点，不用退出去）。

已知坑

· CSS 会覆盖 SVG 的 fill 呈现属性。根节点是浅色实心圆，字必须用 CSS #mapSvg .nd.root text{fill:#0C0E14} 定成深色，写在标签的 fill= 上会被覆盖成白色 → 白字白底，肉眼像"文字被盖住"。交付前用对比度实测，别只看截图。
· 节点多时不要全铺开：11 章 × 最多 5 子节点在一屏放射布局必撞。用渐进披露——同一时刻只展开一个扇形。
· 长距离 scrollTo 用 behavior:'auto'；smooth 滚一万多像素要好几秒，会上像卡死。
· .dim 态的选择器优先级会压过子节点隐藏：#mapSvg.dim .nd:not(.hot)（含 :not，特异性更高）把 .nd.sub 的 opacity:0 顶成 0.22——悬停任意节点时全部收起态子节点会以幽灵小圆漏出来（2026-07 Mori v4 实测）。修法：加 #mapSvg .nd.sub:not(.open){opacity:0!important}。
