# MadSpace 获客全流程 SOP

> 适用场景：中国大陆硬件品牌方 → 出海众筹（KS/IGG）代运营获客
> 团队配置：创始人 + 小团队（2-4人可执行）
> 策略：主动出击 + 被动吸引双轨并行

---

## 二、线索来源矩阵

### 渠道 1：KS/IGG 裸奔中国项目（金矿，值得花最多力气）

**怎么找：**
- KS Discover：按品类筛，排序用 Newest / End date soon；Location 也能筛
- 重点翻 Coming Soon / Prelaunch 页（还没 launch = 最佳介入点，还救得回来）
- Indiegogo Explore 同理，InDemand 里也有
- Kicktraq 这类数据站看日筹款曲线——曲线平掉的一眼就是"做得差"

**怎么认中国团队：** 团队地址露深圳/广东/杭州、中式英文文案、典型 3C/户外/EDC 品类、评论区有中文、创始人名字

**怎么判断"差 = 好切入"（痛点越明确越好谈）：**
- 进度条卡住、没拿 Projects We Love
- 页面糙：渲染图粗、没视频、KSP 没讲清
- 头 48h 就乏力 = launch 前没攒名单（这正好是你最强的点）
- 评论里有抱怨（发货、沟通）

**怎么找到人：** 项目页的官网/社媒链接 → 领英找创始人；FAQ/Risks 露公司名 → 企查查反查；产品名丢小红书/微博/抖音搜 → 很多团队有中文号 → 私信。能挖到微信最好，中国团队微信成单最快。

**触达角度（关键）：** 不是"要不要合作"，是"我看了你 XX 项目，有几个具体问题点（预热名单太小/落地页留资差/广告 ROI），我们帮同品类 YY 做到了 Z 万，案例在这"——给价值、给对标、给证据。

**每周节奏：** 固定品类清单，每周扫 N 个新 live + N 个 prelaunch + N 个数据差的，录表。

### 渠道 2：刚拿融资的硬件公司

**在哪找：** IT桔子按「智能硬件/消费电子/IoT/可穿戴」筛近 1–2 周融资事件；36氪融资快讯、烯牛数据、企名片同理。

**怎么判断：** 天使~A 轮（早期、有钱、要出海但还没成熟海外团队）、品类对口、有实体产品、创始人提过全球市场。

**触达：** 融资新闻带公司名 → 企查查/领英/脉脉找创始人或市场负责人。角度："恭喜拿到融资，看你们做 XX，如果有海外计划，众筹是最低成本的海外首发 + 用户验证，我们帮同类做过 YY。"

### 渠道 3：1688/小红书/抖音冒头的原创硬件新品牌、工厂转品牌

**在哪找 + 信号：**
- 1688 搜品类原创款（有自主设计/专利，不是公模白牌）；工厂转品牌的信号 = 开始做 logo、品牌故事、外观专利
- 小红书/抖音搜新奇硬件，找品牌方/工厂老板自营号、刚冒头但产品有原创度的
- 加分：国内已经卖得不错、有原创外观/技术、但海外还是空白

**怎么判断：** 原创度高 + 有国内销量口碑 + 没海外动作 + 创始人有品牌野心。

**触达：** 小红书/抖音私信、主页商务微信；1688 要找品牌决策人不是客服。角度："你们 XX 国内已经跑通，海外是空白，众筹能低成本测款 + 建品牌 + 拿第一批海外用户……"

**提醒：** 这渠道线索温度最低（人家还没想出海），培育周期长，丢长期池慢慢养。

### 渠道 4：京东/淘宝众筹「已结束项目」反查（投产比最高）

**为什么有效：** 在国内众筹平台上跑过的品牌，已经被教育过「众筹」概念，有产品、有供应链、有团队。国内众筹结束后，天然需要找下一个增长渠道——出海 KS/IGG 是最顺的下一步。

**操作：**
1. 京东众筹 → 筛选「已结束」→ 按金额排序
2. 锁定品类：3C 数码、智能硬件、家居电子、户外装备、健康科技
3. 筛选标准：国内众筹金额 ≥ ¥300,000（说明有基本市场验证）
4. 查品牌方公司名 → 企查查/天眼查找法人/股东 → 联系方式
5. 记录到线索表

### 渠道 5：CES/IFA/香港电子展参展商名单（B2B 富矿）

这些展会的中国参展商有产品、有预算、有出海意愿。展会结束后，他们是最好触达的——刚花了几十万参展，对海外市场有真实需求。

### 渠道 6：即刻/小红书「出海硬件」内容搜索

即刻和小红书上有大量硬件创业者/独立开发者发布产品进展。话术不要太销售："看到你在做 XX，很有意思。我们刚好在 KS 上跑过同品类项目，有些数据可以分享给你参考。"

### 渠道 7：Amazon 上的中国品牌卖家（已验证市场）

Amazon 上跑通的品牌有真实销售数据，说明产品-市场匹配成立。KS 对他们是品牌升级+新渠道。

### 渠道 8：36氪/虎嗅/创业邦「硬件/出海」报道

被科技媒体报道的品牌正在寻求曝光，有融资或新品发布节点，团队处于「对外沟通」状态，触达成功率远高于冷启动。

## 三、线索筛选与打分卡

### 硬门槛（一票否决）

| 维度 | 通过标准 | 否决条件 |
|---|---|---|
| 产品阶段 | 已有工程样机/试产 | 只有 PPT/渲染图 |
| 供应链 | 有量产能力或明确代工厂 | 完全没做过硬件/不懂生产 |
| 出海意愿 | 明确想进海外市场 | 只想做国内、顺手问问 |
| 预算 | 能接受 $15K+ 营销预算（最低档） | 觉得「花几千美金试试水」 |
| 合规 | 产品能过 CE/FCC/UL | 品类在 KS 禁售名单上 |

### 打分卡（满分 100，60 分以上进入正式跟进）

| 维度 | 权重 | 评分标准 |
|---|---|---|
| 品类匹配度 | 25 分 | KS 上同品类有 $500K+ 案例(25) / 有案例但量级小(15) / 品类冷门(5) |
| 产品差异化 | 20 分 | 有明确的技术/设计护城河(20) / 有差异但不明显(12) / 同质化严重(5) |
| 团队背景 | 15 分 | 连续创业者/大厂出身/有出海经验(15) / 做过硬件/有供应链(10) / 首次创业(5) |
| KS 适配度 | 15 分 | 产品有视觉冲击力/有「演示性」(15) / 偏功能性但可拍(10) / 很吃体验/不好展示(5) |
| 资金实力 | 15 分 | 已融资/自有工厂(15) / 有团队有办公室(10) / 个人创业资金紧张(5) |
| 决策链 | 10 分 | 直接和创始人聊(10) / 需要过合伙人(6) / 大公司层层审批(2) |

## 四、触达与建联流程

### 触达渠道优先级

| 优先级 | 渠道 | 适用场景 |
|---|---|---|
| 1 | 共同联系人转介绍 | 最佳，信任门槛最低 |
| 2 | 即刻/LinkedIn 私信 | 创始人活跃的平台，非推销口吻 |
| 3 | 行业群内自然互动→加微信 | 先混脸熟再私聊 |
| 4 | 邮件 | 有官网的品牌方，正式但回应率低 |
| 5 | 官网 Contact Us | 备选，配合其他渠道 |

### 建联后「诊断」流程（核心转化环节）

30 分钟电话/面谈框架：
1. **竞品扫描（5 分钟）**：KS 上同品类最好的三个项目，核心打法
2. **定价诊断（5 分钟）**：KS 成交均价区间，BOM+渠道利润反推定价
3. **预算推演（5 分钟）**：目标 × 17.96% 公式反推营销预算
4. **风险提示（10 分钟）**：审核风险、竞品错位、上线时间窗口
5. **下一步建议（5 分钟）**：先做 XX，出方案看看合不合拍

### 促成签约的关键动作

| 时机 | 动作 |
|---|---|
| 方案发出后 24h | 微信确认收到，问"有没有哪个部分需要解释" |
| 方案发出后 3 天 | 发一条品类新闻/竞品动态（不给压力，刷存在感） |
| 方案发出后 7 天 | 约电话："方案里有个定价策略的新数据想更新给你" |
| 方案发出后 14 天 | 坦诚问："时间不合适还是方向不对？我们可以调整" |

**沉默处理原则：** 品牌方不回复很正常，不要天天催。每次联系都要带新信息。3 次带价值的信息后仍无回应 → 降级为培育池，每月一次资讯触达。

## 五、签约前 Check List

- [ ] 产品有可演示的工程样机/试产版本
- [ ] KS 品类在允许范围内，无合规风险
- [ ] 品牌方能提供产品的核心差异化故事
- [ ] 品牌方能接受 $15K+ 的基础营销预算
- [ ] 决策人（能拍板签约的人）已参与沟通
- [ ] 品牌方对 KS 周期（预热30天+众筹45天）有合理预期
- [ ] 已和品牌方就目标金额达成初步共识
- [ ] 合同条款已确认（服务范围、付款节奏、数据归属）

### 周度节奏

| 动作 | 频率 | 时间 |
|---|---|---|
| 扫京东/淘宝众筹已结束项目 | 每周 | 周一上午 |

| 指标 | 目标 |

| 新增线索 | 25-35 条 |
