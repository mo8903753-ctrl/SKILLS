# 变量拆分规则

收到产品资料后，先把信息拆成四类。已有信息不重复问，缺失但能调研得到的先调研，关键商业变量缺失再问用户。

## 用户输入变量

必须优先从用户材料中提取：

| 字段 | 说明 | 缺失处理 |
|---|---|---|
| product_name | 产品名 | 必问 |
| brand_name | 品牌名 | 可用产品名占位 |
| category | 产品品类 | 根据资料推断，不确定再问 |
| platform | Kickstarter / Indiegogo / Makuake / Zeczec | 默认 Kickstarter/Indiegogo 美国众筹 |
| target_market | 目标市场 | 默认美国 |
| funding_goal_usd | 众筹目标金额 | 必问 |
| aov_or_price | AOV / 早鸟价 / 客单价 | 可先用竞品价格带估算，并标注预估 |
| launch_date | 众筹开始日期 | 缺失时保留占位 |
| end_date | 众筹结束日期 | 可按 45-60 天推算 |
| prelaunch_days | 预热天数 | 默认 30 天 |
| campaign_days | 众筹天数 | 默认 45-60 天 |
| sample_units | 样机数量 | 缺失时按 KOL 计划反推 |
| core_features | 核心功能和卖点 | 从资料提取，不足时调研补强 |
| assets | 产品图、渲染图、视频、logo | 缺失时用占位，不伪造产品实物 |

## 调研生成变量

这些变量必须基于联网搜索、竞品页面、众筹页面、YouTube 或公开资料生成：

- 同品类众筹案例：项目名、募集额、backers、价格、品类、启发。
- 竞品对标：竞品名称、功能、价格、定位、优劣势、对本项目的差异化启发。
- 市场洞察：品类容量、消费者需求、痛点、购买触发点、信任阻碍。
- 用户画像：3-5 类核心人群、场景、痛点、沟通重点、素材方向。
- 广告标签：Meta 兴趣标签、Google/YouTube 搜索关键词、竞品关键词、placement 方向。
- KOL 候选：频道名、链接、订阅量、内容类型、推荐理由、预算层级、截图路径。

## AI 生成变量

这些内容可由模型生成，但必须建立在产品资料和调研结论上：

- 英文 slogan + 中文解释。
- 传播核心概念。
- 用户画像场景图提示词。
- 广告图片方向。
- 页面和广告素材建议。
- 阶段打法标题和策略摘要。

## 固定内容

以下属于模板固定内容，除非用户明确要求更新，否则不要改变：

- MadSpace 公司介绍、服务保障、成功案例、团队配置、汇报机制、联系方式。
- Benchmark 指标框架。
- 预算表结构、订单来源结构、排期结构。
- 模板固定图片、固定 logo、固定背景和固定版式。

## 提问原则

第一轮只问会阻塞方案的变量：产品名、品类、目标金额、AOV/价格、平台/市场、上线时间、样机数量。其他内容优先通过资料和调研补齐。
