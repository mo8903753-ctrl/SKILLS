# 调研流程

所有市场洞察、用户画像、竞品对标、概念打法和 KOL 推荐必须来自产品信息 + 当前调研。

## 竞品和市场

优先搜索：

- 同品类 Kickstarter / Indiegogo 历史项目。
- 同类产品官网、Amazon、品牌站、评测站。
- 众筹页面上的价格、backers、募集额、卖点和评论。
- 消费者痛点和应用场景。

输出至少包括：

| 模块 | 最低要求 |
|---|---|
| 品类容量 | 3-5 个可对标项目或产品 |
| 价格带 | 早鸟价、MSRP 或竞品售价 |
| 用户痛点 | 3-5 个高频痛点 |
| 购买触发点 | 3-5 个理由 |
| 信任阻碍 | 交付、价格、技术、合规、售后等 |

如果信息可能变化，必须联网确认最新数据。不要凭旧记忆写募集额、backers、订阅量或价格。

## 用户画像

根据调研结果生成 3-5 类画像。每类必须包含：

- 人群名称。
- 典型场景。
- 核心痛点。
- 沟通重点。
- 适合素材方向。
- image generation 提示词。

用户画像图片必须用 image generation / image2 生成，不能用不相关图库图硬凑。生成图应表现真实使用场景，不要生成具体公众人物或冒充真实用户。

## 传播概念

传播概念要从产品差异化和用户痛点中推导，不要泛写。每个项目至少输出 3 条方向：

- 主概念：适合封面、页面首屏和广告主视觉。
- 场景概念：适合广告素材和用户画像页。
- 信任概念：适合高客单价、技术、团队、交付说明。

每条概念给英文标题、英文一句话、中文解释。

## 广告调研

Meta 标签必须按人群分组。默认 5-6 组：

- 核心场景人群。
- 专业/半专业用户。
- 内容创作者或技术尝鲜者。
- 车载/安防/家庭/工作场景等品类相关人群。
- 科技早鸟和众筹兴趣人群。
- 再营销 / Lookalike。

Google / YouTube 关键词默认分为：

- High-intent 高意图关键词。
- Scenario 场景关键词。
- Competitor 竞品关键词。
- In-market / YouTube placements。

## YouTube KOL

KOL 必须通过真实 YouTube 搜索筛选，不得虚构。

每个 KOL 记录：

- channel_name
- channel_url 或 video_url
- subscribers
- content_focus
- fit_reason
- tier：头部 / 腰部 / 中小型
- expected_format：长视频评测 / Shorts / 社媒二创 / 直播
- screenshot_path

截图要求：

- 截取 YouTube 频道页或代表视频页，保留频道名、订阅量或视频标题。
- 截图必须来自真实页面，不用手绘卡片替代。
- 如果 YouTube 页面无法访问，说明原因并保留链接，不能伪造截图。

KOL 分层默认：

| 层级 | 数量 | 粉丝量级 | 用途 |
|---|---:|---|---|
| 头部 KOL | 1-2 | 60-120万或品类头部 | 信任背书和首周爆发 |
| 腰部 KOL | 2-3 | 10-30万 | 深度评测和稳定转化 |
| 中小型 KOL | 3-5 | 1-5万 | 样机置换、长尾内容、素材回收 |

实际数量要按样机数量和预算调整。
