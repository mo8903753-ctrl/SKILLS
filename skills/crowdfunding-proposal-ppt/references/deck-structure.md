# PPT 结构

默认生成 40-55 页完整客户提案。页数可随产品复杂度调整，但不得删除固定能力背书章节。

## 标准章节

| 页码范围 | 章节 | 类型 |
|---|---|---|
| 1 | 封面 | 变量 |
| 2 | 众筹项目目标 | 变量 |
| 3 | 美国市场洞察章节页 | 固定结构 |
| 4-7 | 市场洞察、用户画像、竞品与品类容量 | 调研变量 |
| 8 | 受众定位与营销打法章节页 | 固定结构 |
| 9-12 | 用户画像、传播概念、广告图示 | 调研/AI变量 |
| 13 | 美国众筹策略章节页 | 固定结构 |
| 14-19 | 四面向打法、Meta标签、Google关键词、媒介预算、Benchmark | 调研变量 + 固定框架 |
| 20-24 | 广告节奏、预算释放、数据沉淀、投放经验 | 变量 + 固定框架 |
| 25-29 | 问卷、落地页、SNS、EDM | 固定框架，可小幅变量 |
| 30-33 | KOL 合作参考、KOL矩阵、KOL时间表 | 调研变量 |
| 34-37 | 运营与服务保障、团队配置 | 固定 |
| 38-44 | 预算评估、订单来源、投产比、转化路径 | 预算变量 |
| 45-51 | 公司资质与成功案例 | 固定 |
| 52-54 | 项目排期表和时间规划 | 变量 |
| 55 | 联系我们 | 固定 |

## 可编辑要求

- 标题和正文使用 PPT 文本框。
- 表格使用 PPT 表格或由可编辑形状和文本框组成。
- 流程图和预算转化图使用 PPT 形状和连接线。
- 图像只用于产品图、用户画像、KOL 截图、案例截图、固定模板图。

## 内容密度

- 每页只承载一个主任务。
- 策略页优先用短句、标签和表格。
- 长段落不得直接塞入模板；改为 3-5 条要点。
- 如果变量内容超过模板容量，新增同风格补充页。
