用法

① 作战窗口 .launchgrid → ② 全案周计划表 table.gantt（主模块）→ ③ 周级竖向时间线 .tl2 → ④ 筹款节奏图 .rhythm。规格与硬要求见同目录 timeline-gantt.md。

甘特条用 background-image 画，空格子不需要任何元素，也就不会出现空 div 露出容器底色。类名：.on 筹备/前置 · .pre 预热 · .camp 众筹（实线）· .ext 长档期延伸（斜纹）· .ship 发货 · .ms 关键节点 ◆。

首列 .tk 必须 position:sticky;left:0 且有不透明底色，否则横向滚动时任务名会被内容穿透。

竖向时间线的圆点圆心必须压在中轴线上：grid-template-columns:1fr 70px 1fr，圆点放中间列 justify-self:center。交付前实测偏移应为 0。

tbody 生成脚本

36 行 × 15 列手写必错，用 Python 生成后贴进 <tbody>：

# 甘特表 tbody 生成器（36 行 x 15 列手写必错，用这个生成）
N = 15  # 自然周列数
def row(name, cells):
    tds = ''.join(
        '<td class="g ms">\u25c6</td>' if cells.get(i) == 'ms'
        else (f'<td class="g {cells[i]}"></td>' if i in cells else '<td class="g"></td>')
        for i in range(N))
    return f'        <tr><td class="tk">{name}</td>{tds}</tr>\n'
def cat(t):
    return f'        <tr class="catrow"><td colspan="{N+1}">{t}</td></tr>\n'
def span(a, b, cls):
    return {i: cls for i in range(a, b + 1)}

body = ''
body += cat('关键节点')
body += row('预热正式开始（8/15）', {4: 'ms'})
body += row('众筹正式上线（9/15）', {8: 'ms'})
body += cat('必备前置 · 品牌方')
body += row('美国实体注册与收款账户', span(0, 2, 'on'))
body += cat('预热期 · 8/15 → 9/14')
body += row('预热 Ads 启动与 CPL 校准', {4: 'pre'})
body += cat('众筹期 · 9/15 上线')
d = span(8, 11, 'camp'); d.update(span(12, 13, 'ext'))   # 实线=30天档期, 斜纹=45天多出的周
body += row('KOL 评测解禁与分批释放', d)
body += cat('发货期')
body += row('订单整理与地址收集', {14: 'ship'})
# 列头：与 body 的列索引一一对应
wk = ['第3周','第4周'] + ['第1周','第2周','第3周','第4周'] * 3 + ['第1周']
