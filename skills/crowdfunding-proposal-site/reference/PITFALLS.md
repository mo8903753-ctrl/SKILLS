# 踩过的坑(Vocci 项目实录)

1. **flex 容器里 .wrap 的 margin:auto 会收缩成内容宽度再居中**,导致整块文字偏移 200px。解法:.wrap 加 width:100%。这个 bug 曾让标题与 3D 主角反复贴边,所有"避让计算"全部失真。
2. **CJK 字体分包晚到 → 滚动标记坐标过期**,姿态映射整体错位。解法:ResizeObserver 盯 body,任何回流自动 remap。
3. **阻尼用帧 dt 且钳太低(0.05s)→ 低帧率环境收敛不完**,截图全是中间态。解法:dt 上限放宽到 0.25s,按墙钟收敛。无头 QA 环境只有 ~2fps,先想到这一条再怀疑姿态数值。
4. **计数器选择器误伤**:`.num` 同时被表格右对齐样式复用,无 data-n 的元素算出 NaN。解法:选择器写 `.num[data-n]`。
5. **半透明卡片底会把背后的 3D 主角透出来**,看着像遮挡。关键信息卡(定价档)必须不透明底。
6. **透视近端放大**:倾斜的 3D 主角前缘朝相机探出,视觉占位比 z=0 平面估算大 ~20%,避让坐标要按截图实测校正,别信纸面几何。
7. **LatheGeometry 圆角用密集 fillet 点**,真实产品边缘是圆角不是硬倒角;分割线位置对照官方图(Vocci 在离顶 1/4 处擦过按键顶端)。
8. **Netlify Drop 单文件必须叫 index.html**,弹窗点 Rename and deploy;站点名改成项目名再发客户。
9. 内容核对永远先做:预算占比加总、客单×人数≈目标、删内部口径,改一处数字要全局同步(封面统计条/章节标题/合计行)。
10. **主题"中点翻转"在短章节会提前变色**:章节合并变短后,深浅主题在两标记中点切换会切在内容正中。解法:`applyTheme(a.theme)`,跨过标记本身才翻转,CSS 过渡兜底。
11. **删章节必须三同步**:HTML 标记、左侧 rail、章节编号一起改;POSES 留着未引用的键无害,但 rail 漏改会高亮错位。
12. **真实反馈规律**:老板/内部审阅要"结论版"(一页一结论、标题即重点),路演/对外才要"叙事版"动效。开工先问用途,别默认炫技。
13. **rAF 在预览/后台标签被节流 → 滚动动画不动**:视频擦洗、主题翻转(applyTheme)、钉屏场景、电影字幕、漂浮主角若只在 requestAnimationFrame 里更新,预览器(和被切走的真实标签)里滚动不触发更新。解法:同一套 render 再挂 `addEventListener('scroll',()=>render(true),{passive:true})`;rAF 平滑插值,scroll 保证跟手。
14. **章节大标题必须是"章节名"本身,不是小眉题**:老板/客户按章节名扫读——把 eyebrow 里的章节名(.zh)做成大号衬线标题(clamp ~40-62px),章节号小字在上;"一页一结论"那句降为其下 ~26-30px 副标题。别让 14px mono 眉题当标题("太小太小"是真实反复反馈)。
15. **默认正文偏小 → 一开始就放大**:lede ~21-23px、正文/表格/列表/卡片 ~15-16px(不是 13-14)、灰字对比调足(--mut/--faint 调深)。用户几乎每次都要求放大内文,默认就给够。
16. **真 logo 透明浮层、无白底**:品牌真 logo(透明 PNG)浮右上角 + 淡投影,别加白色胶囊底(不高级);先在本机/品牌站找真 logo 文件,别复刻(除非用户同意)。
17. **预览深滚截图会空白 / 钉屏取到错主题**:主题随滚动驱动,把某章 position:fixed 钉屏截图时它显示的是当前 scrollY 处的主题——先 scrollTo 到该章再钉屏,或直接用 computed styles + 元素计数核验,别只靠深滚截图。
18. **真实产品优先于程序化 3D**:能扒到品牌真产品图/视频就别做程序化 3D 主角(用户会说"不对,要真图")。真图路径见 product-video-scrub.md。
19. **`<i>` 是 inline 元素,`width`/`height` 完全不生效** → 用 `<i>` 做的进度条/柱状图填充**永远画不出来**。这个坑极隐蔽:会误以为是"滚动没触发/IntersectionObserver 没跑",改一堆 JS 都没用。填充元素必须 `display:block`(或改用父元素 `background-image` 画条,见 timeline-gantt.md)。**交付前用 `getComputedStyle(fill).width` 实测,不要靠肉眼看截图。**
20. **改 `.wrap` 宽度必须同步 `#rail` 的隐藏断点**:内容栏从 1150→1320 后,导航标签在 1320–1620px 之间**直接压在正文上**(实测压进 79px),而 1440/1512/1536 正是主流笔记本宽度。规则:视口 < wrap + 2×(rail 标签宽) + 余量 时,把标签收成纯刻度(`max-width:0;overflow:hidden`,**连宽度一起收,否则不可见的点击区仍挡正文**)。
21. **全站放大字号后,之后新加的模块会掉队**:后加的章节仍用放大前的 13–19px,与全站 20–25px 并存,同一角色两种字号。**每次新增模块后,跑一遍"同类元素字号一致性"检查。**
22. **hairline 网格(`gap:1px` + 容器底色当分隔线)的空格子会变成实心灰块**:5 个卡片放进 3 列 = 右下角一块带边框的色块,像渲染坏了。**列数必须整除卡片数**,或让末位元素 `grid-column:span 2` 填满行尾。
23. **浏览器缓存会让你验证的是旧版**:改完 reload 看到的可能还是旧文件(实测内联样式改动完全不生效)。验证一律带 `?v=xxx`,发给用户时提醒 Cmd+Shift+R。
24. **品牌 TVC 常烧死英文字幕**:抽帧/剪 hero 前先看底部,需要 `crop=1920:940:0:0` 裁掉字幕带,否则受众照和 hero 上会挂着别人的字幕。
25. **`position:sticky` 元素在移动端被改成 `static` 后,其内 `position:absolute` 的子元素会失去定位父级**:实测产品图跑成 806px 宽、左边 -19px,造成整页横向溢出。移动端要降级 sticky 时改成 `position:relative`,不是 `static`。
26. **网格项默认 `min-width:auto`,长英文词会把列撑破**:`.adtiles` 等含英文文案的卡片网格在手机上撑出 113px 横向溢出。所有卡片网格加 `> *{min-width:0}`。
27. **审计工作流跑的时候不要改被审文件**:验证 agent 读到的是改后的版本,会把真问题判成"证据不存在"而驳回。**也不要在 workflow 完成前读 journal 下结论**(实测读到 24/45 就汇报"只有 1 条问题",最终是 3 条,漏掉的恰是最严重的事实错误)。
28. **竞品价格会过期,交付前必须逐个回源核**:实测 Elemind 写 $349(2024 上市价),官网现价已是 $399;而来源行还写着"官网口径(2025–2026)",等于自证过时。价格锚点、价带上下限、以及所有引用该价的论证句要一起重算。市场数据同理(实测 CAGR 写 7.4%,源站是 7.76%,源里根本没有 7.4)。
29. **改档位命名后,正文里的散引用不会自动跟着变**:把 `$315` 从"早鸟"改名为 Launch Special 后,竞品章/价格锚点/广告素材仍有 5 处写"$315 早鸟",与梯度表直接打架。**改任何档位名/价格后,全文搜旧名。**
30. **删章节/删段落会留下悬空引用**:删掉"4,000 台"那段解释后,风险卡仍写「「4,000 台」口径偏乐观」+「用 add-on 应对」,而这两个词全站已无出处。**删内容后搜一遍被删概念的关键词。**
31. **众筹页的价格上限是 Late Pledge,不是日常零售价**:把"日常零售价 $499"当成一档写进 Reward 梯度表是常见错误——零售价是上线**之后**官网卖的价,它不会出现在众筹页上。KS 页面的最高单品价 = Late Pledge。零售价只能出现在**价值锚点**语境(与竞品零售价横比、证明众筹全程低于零售),并明确标注"非众筹档位"。
32. **删掉一档后要重排网格列数**:7 档在 `repeat(4,1fr)` + 末位 `span 2` 正好填满 2 行;删成 6 档后变成 7 个格位,行尾留一个空洞(同坑 22)。删档/加档后重算:`(档数-1) + 末位跨度` 必须被列数整除,否则改列数。
33. **"主力档"必须真的是量最大的那档**:改梯度时容易只挪标签不挪数量,出现"主力档只占 30% 支持者"而旁边的限量档占 25% 的荒谬形状。真实众筹梯度是**从 Launch Special 起量随价递减**(Late Pledge 是补单档,应当最小;Secret 是订金锁定的小档不参与该检查)。定完梯度先跑一遍:量是否递减、主力档 Launch Special 是否 ≥60%(2026-07-30 拍板)、加权 AOV × 支持者是否 = 目标金额。
34. **主力行和合计行别用同一个高亮 class**:表格里给主力档套 `.hl` 会和"合计"行底色完全一致,读者会当成第二个合计。主力行改用左侧色条(`box-shadow:inset 3px 0 0 var(--acc)`)+ 浅得多的底色。
35. **Vercel 部署卡在 `UNKNOWN` / builds `0ms`,多半是目录里有大文件**:项目里有 147MB 的 `_workfiles/`(原始视频)时,即使 `.vercelignore` 已排除,逐文件上传仍会挂死(实测两次部署 UNKNOWN、同步部署 420s 超时)。两个解法:① 加 `--archive=tgz` 打包成单个 tarball 上传;② 另建只含 `index.html + assets/ + .vercel/` 的干净目录再 deploy。**部署后必须 `curl` 线上 HTML 抓关键数字核验**——旧 alias 会让你看到 200 却是旧内容。

## 通用实现坑(与主题无关,任何方案都适用)

### GSAP
- **`gsap.from()` 残留 transform → 卡片重叠**(125% 尤甚):改 `fromTo({y:36,opacity:0},{y:0,opacity:1,clearProps:"transform"})`。
- **count-up 混合格式数字**(`$500K`、`~$460K`、`1,400+`):`gsap.from({textContent:0})` 会丢前后缀。改计数对象 + 手动 prefix/num/suffix 解析;range(含 `–`)跳过。
- **删除封面元素后残留选择器**:清掉指向已删元素的 GSAP 块(`.orb-accent`、`.cover-eyebrow`),否则 console 警告。

### SVG
- **viewBox 太紧裁切**:最低元素 y 之上留 20-40px。
- **>100% 缩放文字重叠**:行间 y 拉开 ≥18-20px,密集区字号 8-10px,用更大 viewBox(400×380 代替 340×340)。

### 编辑安全
- **禁短数字串全局替换**:`$220` 会污染 `$220–240`→`$150–170–240`。old_string 带足上下文,替换后再搜确认无级联。
- **execute_code 里禁用 hermes `read_file()` 改 HTML**:它带行号前缀(`187|content`),写回会把行号嵌进文件。用 Python 原生 `open().read()/write()`;必须用 read_file 时先 `re.sub(r'^\s*\d+\|','',html,flags=re.M)` 去前缀。

### 反模式(DO NOT)
- 禁外部字体 CDN 之外的外链图片 / `file://` 绝对路径(破坏离线与部署)。
- 禁把硬盘 bundle 设为默认/featured 档(Diskless + Add-On 才对)。
- 禁用国内背书(信创/国家级/中科院/政府部署数)作定价溢价。
- 禁预算写成大额平摊("$200K total marketing")——目标≠营销预算。
- 禁 KPI 不从定价档推导($200K÷$999≠1,500 backers)。
- 禁认证类内容入方案(合规/物流/平台认证,见 `content-methodology.md` §5)。**唯一例外:日本方案的 PSE 认证必须写进风险章**(见 SKILL.md「日本众筹商务方案默认模块」)。
- 禁渠道含 Reddit/HN/Twitter-X/隐私安全媒体(已删)。
- 成功页标题禁"你得到什么",用"Campaign结束后的品牌资产"。
- 玻璃卡禁压产品主体;use-case 卡禁 SVG icon(用数字);封面禁居中文字/过浅均匀遮罩。
- claim 软化:禁"首款"、禁"竞品需 18-24 月追平"(详见 `content-methodology.md` §10)。
