# Benchmark 基准值

以下为预热期固定 Benchmark 值，所有项目通用：

| 指标 | Benchmark 范围 | 说明 |
|------|-------------|------|
| CPM | $18-$20 | 千次展示费用 |
| CTR | 2%-3% | 点击率 |
| CPC | $0.8-$1 | 单次点击成本 |
| CPL | $3-$5 | 单次 Lead 收集成本 |
| CVR | 15%-20% | 转化率（Lead / Click） |

## 颜色标注规则

在 Benchmark 对比表中，当前数据使用以下颜色标注：

- **绿色 (#22C55E)**：优于 Benchmark（CPM / CPC / CPL 低于下限，CTR / CVR 高于上限）
- **红色 (#EF4444)**：差于 Benchmark（CPM / CPC / CPL 高于上限，CTR / CVR 低于下限）
- **蓝色 (#3B82F6)**：在 Benchmark 范围内

注意：对于“越低越好”的指标（CPM、CPC、CPL），低于范围下限为绿色；对于“越高越好”的指标（CTR、CVR），高于范围上限为绿色。
