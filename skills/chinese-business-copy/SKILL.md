# 中文商务文案润色

将机器翻译或英文思维的中文文案，改写为适合中国商务场景正式沟通的版本。

## 适用场景

- 面向品牌方/甲方的方案、提案、汇报文档
- 众筹页面、官网、产品介绍等对外文案
- 需要"能在会议室里逐页讲给对方听"的正式材料

不适用于微信/邮件等短消息——短消息请用 `chinese-client-messaging`。

## 核心原则

### 1. 正式但不僵硬

使用正式文书表达，但句子要有呼吸感，不是堆砌公文体。

✅ 可用表达：
- "本案""该品类""具备条件""予以明确""构成""形成区隔""经市场验证"
- "核心差异化能力聚焦于两点""此处需要说明的是""以下为本案的判断"

❌ 避免：
- 过度口语化：吐槽、堵死、翻车、凑满、就够了、接住、打（如"专打它做不到的"）、拦死
- 网络用语：拉满、到位、硬核
- 缩略语作独立句："超早割"→"超早鸟价格"，"投广"→"广告投放"，"客单"→"客单价"

### 2. 去翻译腔

识别并替换从英文直译过来的句式。

| 翻译腔 | 替换为 |
|--------|--------|
| "核心差异化能力集中在两点" | "核心差异化能力聚焦于两点" |
| "品类被抱怨最多的" | "品类中长期被诟病的" |
| "付费意愿最强的功能" | "该品类中付费意愿最强的能力" |
| "日本人忌讳递设备" | "日本市场对'向对方递送设备'存在较强的社交抵触" |
| "配置向上靠、价格向下打" | "配置向上对齐，价格向下锚定" |
| "正面解决" | "正面回应" / "由本产品针对性解决" |
| "三类对手都在给W4 Plus留位置" | "三类竞品各自为W4 Plus预留了市场空间" |
| "把三家的定位讲清楚" | "三家定位一句话辨析" |

### 3. 判断性表达保持客观化

保留判断力，但用客观陈述替代主观口吻。

✅ "本案的定位明确：不进入旅行翻译工具市场"
✅ "以下风险均为开案前需要明确口径的事项，不构成执行障碍"
✅ "Pocketalk 用十年时间建立的市场信任，为耳机形态的体验升级提供了成熟的用户认知基础"

❌ "这不是能不能做的问题，是开案前把口径定下来"
❌ "Pocketalk 花了十年建立的市场信任，我们接住它"
❌ "我们的定位非常明确：不做旅行翻译工具的生意"

### 4. 句式节奏

- 段落由2–4句组成，长短句交替
- 避免连续3句以上短促的独立陈述（翻译腔标志）
- 使用"——"做句中补充说明，而非每句都用句号断开
- 排比句保持结构一致（如"不进入……不覆盖……不做……"）

### 5. 破除「不是…而是…」——AI 二元对立句式

LLM 有一种根深蒂固的倾向：通过否定一件事来确立另一件事。结果就是满篇「不在…而在…」「不是…而是…」「不只…更是…」「不…不…」。真实商务文档里，没有人这样说话。

**识别并改写以下 AI 句式：**

| AI 句式 | 问题 | 替换方式 |
|:---|:---|:---|
| 「LumiSleep 的机会不在A，而在B」| 用否定来建立判断——会议室里不会这样开口 | 「LumiSleep 的机会，是把A和B同时握在手里」/ 直接陈述 B |
| 「不是又一个X，而是Y」| 先树靶子再立自己——AI 最爱的反驳体 | 直接说 Y 是什么，不提 X |
| 「不靠A、不靠B——直接做C」| 连续否定堆叠，读起来像声明而非判断 | 「直接做C。与A、B无关。」 |
| 「不只X，更是Y」| 递进式的 AI 强调，没有信息增量 | 「X 是基础，Y 才是我们切入的角度」/ 或直接说 Y |
| 「别人X，我们Y」| 用他人做垫脚石——真实提案里显得小家子气 | 不提别人，直接讲自己的价值 |

**核心原则：正向陈述优先。** 能直接说一个东西是什么，就不要先说它不是什么。只在需要与竞品做出关键区隔、且区隔本身有信息量的情况下，才使用否定句——而且一处足矣，不要篇篇都用。

**改写示例：**

❌ 「LumiSleep 的机会不在再做一台更准的睡眠追踪器，而在成为少数直接干预、让你更快入睡的闭环脑电设备。」
✅ 「LumiSleep 的机会很简单：成为少数直接干预、让你更快入睡的闭环脑电设备。」

❌ 「不是帮你追踪睡眠，是让你睡着。」
✅ 「追踪是别人的事。LumiSleep 只做一件事：让你睡着。」

❌ 「不靠心率、不靠动作反推，直接读脑波。」
✅ 「四通道 EEG，直接从额前皮层读取脑电——精度的来源是传感器位置，不是算法。」

❌ 「不是堆砌公文体。」
✅ 「句子要有呼吸感。」

### 6. 数据与逻辑完整保留

所有的数字、表格、逻辑关系完整保留，不做简化或折损。这是商务文档的骨架。

## 改写流程

1. 读一遍原文，标出所有"读不下去"的句子——翻译腔、二元对立句式（不是…而是…/不在…而在…）、连续否定堆叠（不…不…不…），这三类是最常见的病灶
2. 找出主语不明、省略不当、动宾搭配奇怪的位置
3. 先修复翻译腔，再把所有二元对立句式改为正向陈述，然后调整正式度，最后统一句式节奏
4. 通读检查：能否流畅地在会议上逐段念出来？有没有哪句话像是在"反驳一个不存在的观点"？
