# 动效库（26 个原语）

**规则**
1. 参考页的每一个动效必须 **100% 还原**——这是下限。
2. 在还原之外，**至少再额外加 2 种参考页没有的原语**，且每一种必须服务一个具体卖点（不是为炫而炫）。
3. 全页**至少 8 种不同原语**，**至少 6 个整屏钉住场景**（滚动长度 240–420vh）。
4. **相邻两屏不得重复同一种原语。**
5. 每个原语都要回答：*它在证明哪一句文案？*

实现参考：`examples/sweetmyo-gen2-v4/src/element.js`（函数名见「标杆位置」列）。  
通用滚动写法见本文末「场景引擎」。

## 场景引擎（标杆做法）

```js
// 1) 每个场景是外层高 240–420vh、内层 position:sticky; height:100svh 的容器
// 2) 每帧读 rect → 进度 p ∈ [0,1]，再对 p 做缓动平滑（k=.14–.18）
var target = clamp(-r.top / (r.height - vh), 0, 1);
sc.cur += (target - sc.cur) * sc.k;
sc.update(sc.cur, r, vh);
// 3) update(p) 里只写 transform / opacity / clip-path，不读布局
// 4) 离开视口的场景不更新；视频/canvas 用 IntersectionObserver 暂停
```

分段小工具：`seg(p,a,b) = clamp((p-a)/(b-a),0,1)`；缓动：`easeInOut / easeOut / smooth(t)=t*t*(3-2t)`。

## 额外原语的挑选方法
先写出每个卖点的一句话，问：**“怎样的动作能让用户不读字就懂这一句？”**
- 「更舒服」→ 波形从尖刺变平滑（#14）
- 「覆盖全身」→ 身体逐区点亮（#15 / #19）
- 「会跟着你动」→ 多段真实运动视频 + 脉冲线跟着节奏变（#23）
- 「易穿戴」→ 部件爆炸或一键扣合特写（#17 / #8）
- 「数据看得见」→ 扫描线 + 大数字（#4 / #10）
- 「App 智能」→ 3D 转盘（#20）
