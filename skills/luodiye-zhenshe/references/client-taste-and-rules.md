# 客户偏好与规则

这些都是客户在过往项目里明确说过、或打回过的。按"违反就会被打回"的标准执行。

## 一、工作方式

1. **只改指出的地方。** "有些 X 不太行"指的是个别几处，不是全页。先列出你认为有问题的具体位置和改法，再动手。参考站是借思路（信息组织、表达方式），不是把它的样式照搬到全页。
2. **删除前确认范围。** "这里不要"可能是删整块，也可能只是删里面重复的素材。拿不准就问。
3. **"设计大改 / 重构 / 完全超出"= 换形态。** 旧版只当内容库，重新规划版式和叙事，不在旧结构上精修。
4. **"太 AI / 廉价 / 平淡 / 太丑"= 换方向重做**，不是微调。
5. **建议只提一次。** 风险、可选优化提一次写清后果即可；客户没接就是不做，收尾不要每轮挂"还剩 N 件事"。
6. **对外和不可逆的操作先确认**：发布网站、发消息、删除东西。客户每次说"可以发布"只对那一次有效。
7. **汇报要诚实**：哪些在线上验证过、哪些只在本地看过、哪些没测（真机、表单提交），分开说。
8. **浏览器操作**：客户自己的环境规定用 Ego Lite（`ego-browser`），在独立任务空间操作，不抢他正在用的浏览器窗口。用完关闭任务空间。
9. 文案沟通用中文；页面上的文案是英文。

## 二、文案

- 正文只能用文案表（飞书英文定稿列）里的句子，不要自己改写。
- 必须补的小字（图片说明、按钮、标签）可以写，但交付时要列出哪些不是原句，提醒客户找品牌方确认。
- 产品参数只能用品牌方给的。没有官方数据的（例如轴体总行程）不要标数字。
- 生成的工艺示意图在画面上标 "Process visualization"。

## 三、视觉

### 要的
- 酷炫、高级、动效交互拉满，追 Awwwards 级别。参考过的站：electronicmaterialsoffice.com、knob.design，以及苹果、Razer、Wooting 的产品页。
- 产品级落地页用产品自己的气质：biaXbew 用的是深色舞台 + 骨白字 + 少量雕刻金，Archivo 宽体大标题 + JetBrains Mono 小字。（注意：客户做**提案 deck / 方案站**时用的是另一套浅色衬线风格，不要混用到产品落地页。）
- 产品主展示配色以客户指定为准（biaXbew：亮银为主、烟枪灰其次、黑色只做辅助）。同一画面里产品配色必须一致（出过"上边框银色、下壳黑色"的错误）。
- 每张图都能回答"它在证明哪句文案"；同一镜头全页只出现一次；同一组图片比例一致。
- 素材不裸用：裁切到版位比例、统一调色、压暗背景、去掉道具。
- Kickstarter 用官方绿色字标图，不用文字代替。
- 数字和规格都要有动效：滚动进入视野时从 0 计数，落地时弹一下，每次进入都重播。

### 不要的
- 白底圆角卡片阵列、1px 灰边 + 普通投影的等分卡片、通用线性图标、大数字盒子、到处彩色圆点、ghost 序号、cyan 科技感。
- 手绘的示意图、假手机界面、假软件界面（客户点名过"AI 味太重、没有设计痕迹"）。
- 淡入上浮这类廉价入场动效（被评"低级"）。
- 给画面加说明性标签（如在图上标 "Screen" / "Desk"），大家看得懂。
- 开场加载动画。
- 交互时页面整体颜色乱跳。
- "标签 + 滑块 + 框里换图"式的卖点展示（被评"不优雅、没灵魂"）。
- 卖点画面里配角抢戏：例如屏幕同步卖点铺满屏幕画面，像在卖屏幕。**卖点画面的落点必须是产品本身**，配角只做过场。
- 画面残留：转场结束时上一张图的残影必须完全消失。

## 四、交互

- **页面上不能有"必须点击才出现"的内容。** 所有切换要自动播放或跟随滚动；用户点击只是临时接管几秒，之后恢复自动。
- 自动切换间隔要短（biaXbew 最终统一为 1.5 秒），不要"鼠标悬停就暂停"。
- 不要卡顿：避免全屏噪点动画、混合模式大面积使用、毛玻璃、运行时模糊和大投影。
- 首屏要立刻有内容，不能长时间黑屏。

## 五、收集邮箱（硬性要求）

- 必须是 **Wix 原生表单**，数据进 Wix 后台。客户只信 Wix 后台的数据。
- 输入框直接在页面上，**只输一次**，点提交后**直接弹 Wix 原生弹窗**（进群、付定金或问卷）。
- 位置和范例一致：首屏、中段、结尾各一个。不要常驻底栏，不要"点按钮再弹出输入框"。
- 不接受自己写代码收集或转存邮箱。
- 不要用测试邮箱往真实表单里提交，除非客户同意；测试邮箱用 example.com 并在交接时说明。

## 六、交付格式

- 本地预览 + 截图总览图发给客户看。
- 发布前列清楚改了什么，得到同意再发布。
- 项目交接写一份只写当前状态的交接文档。
