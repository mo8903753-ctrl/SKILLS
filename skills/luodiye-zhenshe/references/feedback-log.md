# 历次反馈记录

按时间整理客户在两个 Wix 预热页项目上的反馈。规则已经汇总在 `client-taste-and-rules.md`，这里保留原始语境，遇到类似情况时对照。

## Cozio 宠物陪伴机器人（2026-10-12）

| 版本 | 做法 | 客户反馈 |
|---|---|---|
| v1 | Wix 原生搭建，圆角卡片 + 原图 | 设计简单，排版和图片处理达不到成品要求 |
| v2 | HTML 手绘户型对比图、仿手机 UI 浮卡、淡入上浮动效 | AI 味太重、没有设计痕迹；淡入上浮"低级" |
| v3 | 全部用实拍（视频切片、开箱视频做滚动转台）、大字、单一品牌色、GSAP 滚动编排 | **方向认可**，但要求全部能在 Wix 原生呈现 |
| v4.1 | 每条功能文案配能说明它的画面，片段剪成完整动作 | 之前"素材没用充分、片段放一半不知道在干嘛、相似度高、图没体现文案" |
| v4.2 | 全页统一区块语法 | 之前"区块内图文排版乱、和范例完全不符" |
| v4.3 | 去白卡片、按品牌 VI 做图标、媒体槽位与素材同比例、字号放大（标题 72、说明 22、正文 17） | 之前"卡片和图标太大众、图被截断、字号偏小" |

教训：先定一套区块模板再填内容；正文字号不小于 17px；媒体按版位比例重新导出，不靠 CSS 裁；核心人群决定选图（Cozio 选狗不选猫）；实物和渲染配色不一致时以实物为准。

## biaXbew Genesis01（2026-10-13 至 10-16）

| 轮次 | 客户反馈 | 处理 |
|---|---|---|
| 开工 | 完全彻底扫描所有素材；素材要处理不能裸用；页面要酷炫、动效交互拉满；结构和 CTA 按范例 | 全量盘点 1144 张；灯效连拍对齐；抠图校正；滚动编排 |
| 落地方式 | 要放在 Wix；邮箱必须是 Wix 原生（数据要在 Wix 后台）；必须有输入框、只输一次、点了直接弹窗；不要常驻底栏；不接受动效降级 | Wix 自定义元素 + 原生表单叠放，运行时对位 |
| 第 1 轮 | 卡顿、加载慢；删开场加载动画；Kickstarter 用官方 logo；灯效区不点也要变化；画面不要标 Screen / Desk；不能有需要点击才出现的内容；数字规格要有跳动动效 | 去掉高耗能效果；全部自动播放；数字计数 + 弹跳 |
| 第 2 轮 | 首屏黑屏时间长；20+ 数字跳完会消失；打字区键盘比例怪；三模、场景轮播仍要点击或太慢；续航拖动时颜色乱跳 | 首屏原生静帧兜底；动效库内联；可见性改 IntersectionObserver；渐变字弹跳挂父级；间隔缩短 |
| 第 3 轮 | 宽屏首屏错位；打字区键盘比例仍错 | 版式按页面边距排，表单运行时对位；手机版完成 |
| 第 4 轮 | 屏幕同步段铺开后像在卖屏幕，要键盘高亮、屏幕随滚动变暗、键盘占据主要位置；工艺长廊第二张宽度不同 | 镜头推向键盘 + 径向压暗；统一比例 |
| 第 5 轮 | 工艺和轴体两段"有那个意思但缺少灵魂、单调、滑动换图不优雅"；要多搜竞品（苹果 CNC 等）的动态表达，按竞品做素材，让用户看懂卖点 | 参考苹果、Razer、Wooting 做成整屏滚动短片：刀路揭开、慢动作按压 + 刻度 |
| 第 6 轮 | 工艺段有画面残留；横向长廊不要删，只删重复素材 | mask 结束时补满；长廊只去掉重复的两张 |
| 第 7 轮 | 以亮银为主要款；第二屏键盘壳体颜色不一致（边框银色、下方黑色）；亮银和烟枪灰为主要色，黑色辅助 | 首屏、屏幕同步、定位、工艺末段换银色素材，同一画面配色统一 |
| 文案 | 飞书英文定稿更新后，按定稿替换标题正文；不要新增卖点区块，新增内容并入已有区块 | 只替换文字，不动结构 |
