## 结构（从上到下）

1. 顶栏：品牌 logo（白色版）+ "Launching soon on [Kickstarter 字标]"。
2. **首屏**：大标题 + 副标题 + "Launching Soon on [Kickstarter 字标]" + "Sign up now and enjoy over XX% OFF" + **邮箱框（原生表单 1）**。首屏不滚动就要看到邮箱框。
3. 痛点。
4. 产品定位。
5. 卖点区块（通常 5 至 7 个，每个一屏或一段滚动短片）。
6. **中段订阅条（原生表单 2）**。
7. 更多卖点。
8. 使用场景轮播（3 至 4 个场景）。
9. **结尾 CTA + 邮箱框（原生表单 3）**。
10. 页脚版权。

文案表通常按这个顺序给：标题 → 副标题 → CTA → 痛点 → 产品定位 → 核心卖点（标题 + 正文）→ 使用场景轮播 → 结尾 CTA。

## 文案

- 英文列是定稿，原句照用。中文列只用来理解。
- 品牌方原始卖点（文案表里的 KSP 页签）是产品事实来源：材质、参数、配色、和竞品的差异。可以用来决定画面怎么拍、怎么表达，但不直接上页面。
- 折扣力度、价格没有确定时，页面用中性话术，不写具体数字。
- 页面上必须补的小字（图片说明、标签），交付时单独列出"非文案表原句"清单。

## Kickstarter 字标

- 用 Kickstarter 官方绿色字标图（客户站点媒体库里通常已有），放在 "Launching Soon on" 后面，高度约 17px。
- 不要用文字 "KICKSTARTER" 代替。

## biaXbew 最终版的区块（参考）

| 区块 | 做法 |
|---|---|
| 首屏 | 3D 产品（抠图 + 校正的俯拍）跟随鼠标倾斜，滚动时放平并穿入痛点文案，痛点逐词点亮 |
| 屏幕同步 | 实拍屏幕和键盘同色，三种灯色自动切换；镜头最终落在键盘上 |
| 产品定位 | 三联图自动轮换展开 |
| AI 灯效 | 卡片自动逐字输入灯效描述，9 张对齐过的同机位实拍同步切换灯光 |
| 20+ 灯效 | 渐变大数字 + 两排灯效图无限流动 |
| 机身工艺 | 整屏滚动短片：铝块 → 刀路揭开铣削 → 揭开阳极表面 → 揭开成品弧面；之后横向长廊、底板大图 |
| 中段订阅 | 原生表单 |
| 轴体 | 整屏滚动短片：轴心随滚动按下、刻度尺到 1.1 mm 触发发光、回弹、切到实装微距并计数到 5000 万；之后访客可用自己的键盘打字 |
| 三模连接 | 图标展示 |
| 续航 | 同机位亮灯 / 关灯对比，随滚动擦除，可拖动；小时数计数 |
| 游戏设置 | 实拍 + 功能名 |
| 场景轮播 | 4 个场景自动切换 |
| 结尾 | 原生表单 + 页脚 |

完整源码在 `examples/biaxbew-genesis01/`。
