# 素材处理

脚本在 `scripts/assets/`，需要 Python 3 + Pillow + OpenCV + NumPy（抠图需要 rembg）。
路径通过环境变量设置，**不要把原片复制进项目**（品牌方原片常有几十 GB）：

| 变量 | 含义 | 默认 |
|---|---|---|
| `KS_RAW` | 原片文件夹（只读） | `./raw` |
| `KS_THUMBS` | 缩略图输出 | `./work/thumbs` |
| `KS_SHEETS` | 总览图输出 | `./work/sheets` |
| `KS_TMP` | 临时文件 | `./work/tmp` |
| `KS_OUT` | 网页素材输出（页面的 `assets/`） | `./site/assets` |
| `KS_SEQ_DIR` / `KS_SEQ_THUMBS` | 灯效连拍所在的原片 / 缩略图文件夹 | |

## 1. 全量盘点

```bash
KS_RAW="/path/to/原片" python3 scripts/assets/thumbs.py     # 全部原片 → 1200px 缩略图，多进程
python3 scripts/assets/sheets.py                           # 拼成带文件名的总览图，每张 42 格
```

然后**逐张看完所有总览图**，记录：
- 每个文件夹拍了什么（精修、静物、场景、花絮）。花絮、布光测试不用。
- 产品有几个配色，各自的名字；客户指定哪个是主展示款。
- 哪些是同机位连拍（灯效、亮灭、按键扩散），可以做"同机位切换"。
- 道具和风险：第三方 IP 玩偶、别家品牌、显眼的道具灯牌（biaXbew 的绿色 "RELAXED" 灯牌）。
- 有没有"说明卖点"的画面：每个卖点都要找到至少一张能证明它的图，找不到就记为缺口。

结论写进项目笔记，之后不要重新盘点。

## 2. 每个卖点配画面

- 每张图都能回答"它在证明哪一句文案"。
- 同一个镜头全页只出现一次（换了处理方式也算重复）。
- 同一组图比例一致。
- 主展示配色优先；同一画面里产品配色必须一致。

## 3. 处理方法

`lib.py` 里有通用函数：`load`（读原片并降采样）、`cover`（按版位比例裁切）、`grade`（黑场、gamma、对比、饱和）、`vignette`、`grain`、`save`（导出 WebP，可带透明通道）、`sift_align`（对齐两张同物体照片）。
`lib.py` 里的 `D` 字典是 biaXbew 项目的文件名简写，换项目时改掉。

| 需求 | 做法 | 脚本 |
|---|---|---|
| 灯效 / 颜色切换不跳 | 手持连拍用 SIFT 特征 + 单应变换对齐到参考帧。键帽这类有字符的产品，先取 RGB 最小通道再 CLAHE，让彩色灯光不干扰匹配 | `align.py`、`a_seq.py` |
| 找可用连拍 | 相邻帧特征匹配，找机位几乎不动的序列 | `groups.py`、`ecc.py` |
| 产品正视图（做 3D、做叠层） | rembg 抠图 → 凸包 → 四边拟合直线求交 → 透视校正到实测长宽比 → 圆角透明边 | `b_rect.py` |
| 亮灭对比 / 前后对比 | 两张对齐后同尺寸裁切 | `d_misc.py` |
| 普通裁切调色 | 按版位比例 `cover`，压黑场、轻 S 曲线，暗调产品统一 | `c_assets.py` |
| 产品拆层做动画 | 从抠图里按坐标切出可动部分（如轴心十字），可动层向下补一段相同纹理，静止层挖掉该部分；可动层放下面，静止层在上面遮挡 | 案例中的做法见 `examples/biaxbew-genesis01/HANDOFF-history.md` "工艺与轴体改成滚动短片" 一节 |
| 首屏辉光 | 产品图缩小 → 高斯模糊 → 提饱和提亮，导出成图片，页面上不用运行时模糊 | |

## 4. 生成补缺画面

- 只补实拍里没有、又是讲清卖点必需的画面（例如 CNC 铣削过程、原料铝块）。
- **不能改变产品**：键帽字符、布局、配色、Logo 都要和实物一致；有漂移的候选直接淘汰。
- 生成的过程示意图在页面上标 "Process visualization"。
- 每张生成图保存提示词、候选和淘汰原因。

## 5. 导出规格

- WebP，质量 76 到 86；大图按显示宽度导出（全屏约 2400 宽、版位图 1200 到 1800 宽）。
- 手机版需要的话另出 `@m` 小图。
- 带透明的用 WebP 透明通道。
