# 设计系统（硬规则）

本文件把「客户的审美」写成**可量化、可检查**的数字。所有数字都已由客户逐项确认。  
交付前必须跑 `scripts/qa/page-metrics.mjs`，任何 `HARD` 项不通过就不能交付。

标杆源码：`examples/sweetmyo-gen2-v4/`。拿不准时，照标杆做，不要自己发明。

---

## 0. 一句话
> 大字、大画面、少文字、没有线框。每一屏只讲一件事，用整屏的滚动接管来证明它。

## 1. 字体（四套白名单，每个品牌只选一套，禁止混用）

| # | 主字（标题 / UI） | 强调字（斜体衬线） | 标签字（等宽） | 适用 |
|---|---|---|---|---|
| ① 默认 | Inter Tight 600 | Instrument Serif Italic | JetBrains Mono 500 | 运动 / 科技 / 可穿戴 |
| ② | Instrument Sans 600 | Newsreader Italic | Geist Mono | 健康 / 生活方式 |
| ③ | Archivo 700（**标准宽度**，wdth=100） | Newsreader Italic | IBM Plex Mono | 硬件 / 工业 / 键盘（biaXbew 用过） |
| ④ | Manrope 700 | Cormorant Garamond Italic | DM Mono | 美妆 / 轻奢 |

全部可用 Google Fonts 引用。**白名单之外的字体一律禁止**，尤其是：
- 超粗压缩体 / 窄体（Anton、Bebas Neue、Mona Sans Condensed、Archivo Narrow/Compressed 等）
- 像素体、手写体、科幻 HUD 字体、任何“显示用”装饰字体
- 字距小于 `-0.05em`（会让字母粘在一起，已出过事故）

使用方式：
- **主字**：字距 `-0.04 ~ -0.05em`，行高 `0.9 ~ 1.0`，字重 600。
- **强调字**：只用在标题里**最关键的 1–3 个词**；字号比同行大 `1.06 ~ 1.08em`；同一个标题里只出现一处强调。
- **等宽字**：只用于「眉标」（标题上方的一句话小标签）和倒计时单位；**每个场景最多 1 条**；不用于数字说明。
- 数字说明（大数字下面的小字）用**主字 13px、字重 500、不大写**。

## 2. 字号阶梯（全站只用这几档）

| 角色 | 规格 |
|---|---|
| Hero 大标题 | `clamp(52px, 9.4vw, 156px)` |
| 场景标题 | `clamp(38px, 5.4vw, 88px)`（窄栏标题可降到 `clamp(36px, 4.2vw, 70px)`） |
| 超大数字 | `clamp(96px, 12vw, 210px)`，主卖点数字可到 `23vw` |
| Lead 说明 | `clamp(17px, 1.3vw, 20px)` |
| 正文 | 16–17px |
| 数字说明 / 眉标 / 倒计时单位 | 13px |
| 脚注 / 免责 | 12px（**地板**），只能放页尾或场景角落 |

硬规则：
- **任何文字 < 12px 一律不允许**（包括 `<sup>`：用 `max(12px, .6em)`）。
- **≤12px 的文字占全页字符的比例 ≤ 5%**。
- 手机端同样 ≥ 12px；标题按 `vw` 缩放（Hero 14.2vw）。

## 3. 文字预算

| 范围 | 上限 |
|---|---|
| 每个场景 | **1 个标题（≤8 词）+ ≤1 段说明（≤35 词）+ ≤3 个规格数字** |
| 全页可见字符 | **≤ 5,000** |
| 眉标 | 每场景 ≤1 条，全页 ≤5 条 |
| 数字说明 | 每个数字 ≤3 个词 |

一屏想放第二段话，就拆成第二屏，或者删掉。**宁可删字，不要缩字号。**

## 4. 线框与盒子

- **禁止**：1px 边框盒、四角括号、虚线框、HUD 方框、描边卡片、卡片阵列、`01/02/03` 装饰编号、tab 按钮切换图片、描边药丸标签。
- **允许**：
  - 2px 进度条（顶部全页进度、视频时间条）
  - 当前项的荧光下划线高亮（`background-size` 从 0% 到 100%）
  - 药丸形邮箱表单
  - 整块色块、整屏图片
  - **细分隔线，仅用于规格表与页脚**
- 区块分隔靠：留白、背景色切换、尺寸对比、整屏图片边缘。
- `page-metrics` 允许的带边框元素 ≤6（对应规格表/页脚）。

## 5. 版面

1. 每个场景占满一屏：`position: sticky; height: 100svh` 的舞台，外层高度 **240–420vh**（滚动长度）。
2. 内容分布在**对角两端**（左上标题 / 右下大数字或媒体；或左文右图），**禁止把一个小区块塞进一个角落**。
3. 每屏必须有一个 **≥ 视口 40% 面积**的主视觉（视频 / 照片 / 大数字 / canvas）。
4. 文字栏宽 **≤ 560px**，但字号要大（标题用上面的阶梯）。
5. 相邻两屏**不得用同一种布局或同一种动效**。
6. 页面左右内边距 `clamp(20px, 4.4vw, 72px)`；导航高 68px（手机 58px）。
7. 邮箱表单：药丸形，桌面宽 560–620px，手机满宽 −40px；表单周围只放 **1 行**说明。
8. 手机端：钉住场景保留但简化（横向长廊改纵向；手风琴改纵向展开；3D 转盘缩小）；`scrollWidth == innerWidth`。

## 6. 页面结构（骨架仅作参考，按卖点组织）

- **至少 6–7 屏**，必须包含三个邮箱表单屏：**首屏、中段横幅、终极 CTA**。
- 其余屏由「卖点结构」决定：每个卖点一屏，不要把两个卖点塞进一屏。
- 参考 10 屏骨架（可增减）：首屏 → 钩子问句 → 主卖点演示 → 技术原理 → 覆盖/结构 → 场景手风琴 → 中段横幅 → 数据与 App → 日常使用与安全 → 终极 CTA。
- 结构必须有**节奏**：强开场 → 安静 → 惊喜 → 密集 → 收尾。避免连续三屏都是同一种密度。

### 首屏（两条路径，二选一，必须有滚动接管）
- **A. 全屏真实视频**：视频全屏播放，产品在右侧不被标题/表单遮挡，标题左上、表单左下；向下滚动时视频收缩成标题里的**胶囊窗口**，纸白背景接上下一屏。（标杆已实现）
- **B. 静态图首屏**：用于没有合适视频的产品。要求大图 ≥60% 视口，且必须有滚动联动（例如图片缩放穿入、clip-path 展开、视差分层、部件拉出）。**静态图也要有交互动效，不能只是一张背景。**
- 首屏必须同时出现：标题、一句副标题、邮箱表单、3–4 个带计数动效的规格数字。

## 7. 配色

- 结构规则固定，**配色从品牌方自己的视频 / 官网提取**。
- 全页**最多 3 种背景色**（例：纸白 + 夜黑 + 荧光），只在**章节边界**切换；章节内部不跳色；导航栏在深色章节自动反色。
- 点缀色（荧光色）整页最多一个整屏色块；每个画面里**最多 2 个**元素使用点缀色（高亮词 / 按钮）。
- 文字只用「近黑」与「近白」两档，说明文字用同色 60–75% 透明度，**不要灰色字**（灰字 = 对比不足）。
- 产品颜色必须与客户指定一致，**禁止出现蓝 / 银 / 其它配色变体**（出现过蓝色中控的事故）。
- 渐变只用于遮罩（保证文字对比度），不做装饰渐变。
- 禁止：赛博朋克青色、霓虹多色、彩色圆点装饰、整页黑白反复跳。

标杆取值（荧光运动类）：`paper #F6F5F2` · `ink #0E0F0C` · `night #0B0C0A` · `volt #CBF23A`。

## 8. 素材

**核心原则：素材要证明这一屏的文案。** 不是每屏都要把产品放满——整页都是产品也不好看。按卖点选择或创造最合适的素材：
- 品牌方实拍视频 / 官方图（首选）
- 基于产品图生成的图（不得改变产品本身：颜色、Logo、结构）
- Blender 3D 建模渲染（需要拆解、爆炸图、360° 旋转时）
- canvas / SVG 数据可视化（波形、仪表、热区）——**由真实参数驱动，不是装饰**

规则：
1. **每屏至少一个真实媒体或由真实数据驱动的可视化**。
2. **同一个镜头全页只用一次**。
3. 视频：**只正放**、静音循环、每段 **≥ 4.5 秒**、有 poster；用于 scrub 的视频 `-g 2`（每 2 帧一个关键帧）。
4. 裁切到版位比例（用 ffmpeg / PIL 预先裁，不靠 CSS 硬裁）；同组图片比例一致。
5. 不残留水印、标注文字、制作说明、道具；不使用手绘示意图、仿 UI、假手机界面。
6. 生成的示意图在画面上标 `Process visualization`。
7. 产品出现在画面里时，**不得被标题、数字或表单遮挡**（数字可以压在背景暗部，但不能盖住产品）。
8. 视频码率：桌面 1280–1920 宽、CRF 24–26，单个 ≤ 1.5MB 为宜；图片 WebP，按显示尺寸导出。

## 9. 文案

- 正文只能用官方页 / 文案表 / 品牌方文档里的句子。
- **数字必须与官方资料一致**（500，不是 462）；有冲突（如 200 次 vs 300+ 次洗涤）写进交接文档让客户确认。
- 页面里**不得出现制作说明文字**（`DESIGN PREVIEW`、`WIX FORM`、占位提示等）。
- 非原句的小字（图注、按钮）可以写，但交付时要列清单。
- 学术引用 / 免责放脚注（12px），不要与卖点同级。

## 10. 邮箱收集（Wix）

- 必须是 **Wix 原生表单**，数据进 Wix 后台；页面只预留 3 个 `.wix-form-placeholder`（首屏 / 中段 / 终极），由 `syncWixForms()` 把真实表单平移到占位位置。
- **邮箱表单所在的元素不要放进 `position: sticky` 的舞台里**——表单随页面滚动，而占位在 sticky 里不动，会错位。标杆的做法：首屏标题放 sticky 层，表单放普通流层，随页面一起滚走。
- 提交后直接弹 Wix 原生弹窗（订金 / 进群 / 问卷）；不自己写收集代码。

## 11. 工程

- **滚动引擎**：自写「rect 进度 + 每场景平滑」，场景用 `position: sticky`。**不要用 ScrollTrigger 的 `pin: true`**（pin-spacer 会搬动 DOM，Wix 表单会错位）。GSAP 只用于计数弹跳等小动画。标杆：`examples/sweetmyo-gen2-v4/src/element.js`。
- **平滑滚动**：Lenis `lerp: 0.1`；检测到 Wix 站点（`#SITE_CONTAINER`）时关闭。
- 视频播放/暂停用 `IntersectionObserver`，不要用 ScrollTrigger 的 `onToggle`。
- 性能红线：不用 `backdrop-filter`、大面积 `mix-blend-mode`、运行时 `filter: blur()`、大 `drop-shadow`；需要的光晕预渲染成 PNG（标杆：`assets/v4/glow-volt.png`）。
- 所有 `@keyframes` 加 `sw-` 前缀；全部 CSS 挂在根类下；`disconnectedCallback` 里销毁所有监听、计时器、rAF。

## 12. 禁止清单（速查）

开场加载动画 · 淡入上浮入场 · 全屏噪点 · 毛玻璃 · 运行时 blur · 整页跳色 · tab/滑块切图 · 1px 边框盒 · 角括号 HUD · 装饰编号 · <12px 文字 · 超粗压缩字体 · 字距 <−0.05em · 蓝/银产品变体 · 制作说明文字 · 倒放视频 · 同镜头重复 · 手绘示意图 · 仿 UI · 一个小区块塞进角落 · 整页只有一种动效 · 仅静态背景图的首屏。
