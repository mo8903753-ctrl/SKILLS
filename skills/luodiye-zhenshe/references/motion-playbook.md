# 动效做法手册

先查竞品怎么表达这个卖点，再从下面挑做法。客户认可的做法优先复用。实现代码都在 `examples/biaxbew-genesis01/js/main.js` 和 `css/style.css`，按下面的名字搜。

## 一、客户认可过的做法

### 1. 首屏 3D 产品
- 产品俯拍抠图并透视校正成正视图（`scripts/assets/b_rect.py`），作为 3D 卡片的顶面；下面叠 6 层同色薄片模拟机身厚度；背后放一张预先模糊好的辉光图（不要用运行时 blur）。
- 初始姿态倾斜放在画面右侧；跟随鼠标轻微倾斜 + 一道扫光。
- 滚动时放平、放大并穿入下一屏痛点文案，痛点文字随滚动逐词点亮。
- 机身薄片的颜色必须和产品主配色一致（亮银主款就用银色渐变）。
- 代码：`.kb`、`.kb__layer`、`.pain__text .pw`。

### 2. 同机位实拍切换（讲灯效 / 颜色）
- 用品牌方的灯效连拍，先对齐（`scripts/assets/align.py` / `lib.py` 的 `sift_align`），让键帽字符像素级重合，再切换就不会跳。
- 切换方式：斜向扫光擦除（扫光的位置用 CSS 变量驱动 `clip-path`）。
- 自动播放，访客可临时接管。
- 代码：`#stack`、`.ai__scan`。

### 3. 整屏滚动短片 · 刀路揭开（讲 CNC / 工艺）
- 参考：苹果 unibody "一整块铝 → 多道铣削"。
- 整屏钉住（约 430vh 滚动长度），四段：原料 → 铣削 → 表面处理 → 成品。
- 转场用 SVG `mask`：mask 里是一条粗描边的刀路（光栅往返 / 螺旋 / 弧形），`stroke-dashoffset` 随滚动推进，路径加高斯模糊做软边。刀头处一个发光点，切削时用 canvas 飞出金属屑。
- **每段结束时在 mask 里渐显一块整幅白矩形**，否则刀路没扫到的角落会残留上一张图（客户发现过这个残影）。
- 左下四段进度条 + 当前阶段文案；数字（如 6063）计数。
- 用自己的插值做平滑（ScrollTrigger 只取进度，画面用 ticker 缓动追上），滚轮跳动时也顺滑。
- 代码：`#cnc`、`scrubScene()`、`.cnc__tp`、`.cnc__done`。

### 4. 整屏滚动短片 · 慢动作按压（讲轴体 / 按键 / 机械结构）
- 参考：Wooting 的"轴体 + 触发深度刻度"、Razer 的轴体微距。
- 把真实轴体抠图拆成两层：可移动的轴心、静止的外壳（外壳在上层遮住下沉的轴心）。
- 滚动驱动轴心下压；右侧刻度尺同步；读数到触发距离（如 1.1 mm）时锁定发光、轴体周围亮起、光环扩散；继续按到底，回弹；最后单颗轴体退场，换成实装微距并计数到寿命次数。
- 刻度只标官方给的数字，没有官方总行程就不标。
- 代码：`#press`、`.press__stem`、`.press__gauge`。

### 5. 镜头推进（讲"颜色延伸到桌面"这类和配角有关的卖点）
- 先给配角（屏幕）一个镜头，再随滚动推向产品，产品以外径向压暗，产品最终占据画面主要位置。
- 纯配角的画面不要超过一屏（客户说过"像在卖屏幕"）。
- 代码：`.amb__cam`、`.amb__spot`。

### 6. 数字计数
- 所有数字和规格：进入视野时从 0 滚到目标值，落地弹一下，每次进入都重播。
- 渐变色文字（`background-clip: text`）的弹跳要加在渐变父级上，子元素单独变形会让文字消失。
- 代码：`[data-count]`、`onSeen()`。

### 7. 自动轮播
- 统一间隔常量（biaXbew 是 `AUTOPLAY_MS = 1500`）。
- 只在区块可见时播放；用户点击后暂停几秒再恢复；鼠标悬停不暂停。
- 判断可见性用 `IntersectionObserver`（`watch()` / `zone()`），不要用 ScrollTrigger 的 `onToggle`（在 Wix 里会失效）。

### 8. 亮灭对比（讲续航 / 省电模式）
- 同机位亮灯和关灯两张图对齐；随滚动把灯光"擦掉"，访客也可以拖动分割线；小时数计数。
- 代码：`#dim`。

### 9. 访客自己参与（加分项）
- 访客敲自己的键盘，页面弹出发光键帽、计数，带可关闭的合成按键声（标注"合成音效，不是真实轴体录音"）。没人操作时自动演示。
- 代码：`#type`。

## 二、被否掉的做法（不要再用）

| 做法 | 客户的评价 |
|---|---|
| 白底圆角卡片 + 原图 | "设计简单，排版和图片处理达不到成品要求" |
| 手绘户型对比图、仿手机界面浮卡 | "AI 味太重、没有设计痕迹" |
| 淡入上浮入场动效 | "低级" |
| 标签 + 滑块 + 框里换三张图 | "单调、没灵魂、切换方式不优雅" |
| 开场加载动画 | 要求删除 |
| 画面上标 "Screen" / "Desk" | 不需要 |
| 两屏都是屏幕画面、键盘很晚才出现 | "像在卖屏幕不是卖键盘" |
| 轮播 3.4 秒、悬停暂停 | "需要点击才能切换或者切换时间很长" |
| 全屏噪点、毛玻璃、运行时模糊 | 卡顿 |

## 三、性能要求
- 不用 `backdrop-filter`、大面积 `mix-blend-mode`、运行时 `filter: blur()`、大 `drop-shadow`。需要的模糊和光晕预先做成图片。
- 全页辉光颜色变量限频更新（约 10 次每秒），只写到页面根元素。
- 图片用 WebP，按显示尺寸导出（产品抠图约 2000 到 2400 宽）。
