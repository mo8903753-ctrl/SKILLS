# Research Workflow

Use this workflow when sourcing new YouTube KOLs.

## Search Paths

Start from the campaign category and likely comparison products:

- YouTube search: `{category} review`, `{competitor} review`, `{problem} gadget review`, `{category} Kickstarter review`.
- Web search: `site:youtube.com "{category}" "Kickstarter"`, `site:youtube.com "{category}" "Indiegogo"`, `"{competitor}" "YouTube review"`.
- Campaign/platform search: Kickstarter or Indiegogo pages for similar products, then search each reviewer or press mention on YouTube.
- Creator network expansion: inspect collaborators, comments, related channels, playlists, and channels that covered similar hardware.

## Candidate Validation

For each channel, verify:

- Current channel URL and an example relevant video URL.
- Subscriber count and total views if public.
- Recent average views from relevant long-form videos, preferably the last 5-10 videos in the same content style.
- Whether Shorts views are being mixed with long-form review performance.
- Country/location or primary market.
- English-language suitability.
- Public contact route: About page email, website contact, business email, agency page, or social link.
- Evidence of crowdfunding, launch products, prototypes, Kickstarter, Indiegogo, or early-access reviews.
- Comment quality: technical questions, buying intent, audience trust, and creator responsiveness.

## Search Query Templates

Use combinations like:

```text
site:youtube.com "{product category}" "Kickstarter"
site:youtube.com "{product category}" "Indiegogo"
"{competitor product}" "review" "YouTube"
"{category}" "gadget review" "Canada"
"{category}" "review" "United States" "YouTube"
"best {category}" "review" "YouTube"
"{category}" "hands on" "Kickstarter"
```

## Ranking Method

1. Remove hard rejections.
2. Group candidates by relevance tier:
   - Direct niche reviewers.
   - Adjacent tech/product reviewers.
   - Broader lifestyle or creator channels with a clear use case fit.
3. Score candidates with `references/scoring-rubric.md`.
4. Sort by `MadSpace Advice`, then by cost efficiency, then by market priority, then by recent average views.
5. Keep a short rationale in `MS Notes` and a direct outreach angle in `Note For PR`.

## Evidence Rules

- Cite or include URLs for source pages used.
- Do not fabricate fees; write `Need verify` if no public or historical quote is available.
- Do not fabricate private emails. If a YouTube About page hides email behind login/CAPTCHA, write `Email on About page - verify manually`.
- Use the date of research in `Source checked date`.
- If current data is unavailable, explain the gap and keep the recommendation conservative.
