# 工具与安装后的能力检查
技能是工作指令，不包含模型权限、登录或外部程序。先检查宿主真实可用工具，不声称“安装后全都能用”。

|能力|用途|接收方必须提供|缺失时|
|图片生成和局部编辑|完整成图及修订|支持参考图输入的实际生图工具/额度|标记 BLOCKED_IMAGEGEN；禁止改用 Figma、代码或提示词代替成图|
|图片查看|逐张QA|读取本地/工具返回图片的能力|不能宣称完成视觉检查|
|文件读写与ZIP|保存/清单/包|文件工具，脚本可用Python3|保存可用产物并说明缺口|
|ego lite|网页/Figma UI操作|ego程序、登录、独立task space|未安装或启动失败先说明，再按宿主能力回退|
|Figma写入|实际素材库|用户自己的文件权限或连接器授权|输出待入库，不称已交付|
|lark-cli|读取飞书资料|已安装CLI+当前用户授权|用当前授权资料或允许的浏览器读取|
|ffmpeg|TVC准确取帧|可用解码器|不要伪造原片帧或时间|
|Meta Marketing API|真实广告数据|官方API授权|无指标就做探索，禁止浏览器进账户后台|

本仓库不二次分发第三方支持技能。imagegen、ego-browser、lark-shared、lark-sheets 由接收方通过原作者或宿主支持的渠道安装，并核验实际工具可用。当前宿主已有更新的同名skill时优先保留并遵守宿主约束；不要覆盖运行时系统工具要求。核心与支持文档冲突时，当前用户/系统要求优先。

## 可移植调用
内置 image_gen 或当前宿主等效工具：先看输入图，每张单独调用一次，保存完整prompt、参考文件顺序、返回的真实路径，随后复制到项目目录。不能假设工具名字、结果字段或文件保存目录完全相同。没有工具不能通过安装这些文档获得工具。

Figma 有连接器时只在只读参考或完整位图入库阶段加载必要的前置技能，不路由到广告设计/模板重建流程。没有时 ego UI 导入完整 PNG/JPG；兼容导入必须用 SVG 包装时只允许单一位图，不得夹带文字、形状、遮罩或重排。不要注入未公开Figma内部对象或绕过权限。

ego每个任务使用一个task space，多轮复用；不要带入原作者space ID、页面label或节点ID。完成保留结果页，其余按ego文档清理。若用户接管，按工具规则停止，不绕过。

飞书读取当前表格，不把案例旧revision当实时。凭据不得复制到项目或对话；接收方自行登录。
