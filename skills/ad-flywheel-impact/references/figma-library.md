# Figma 与素材清单规范

## 页面组织

在指定文件建立项目专属页面；已有同项目结构则续用。多项目文件添加项目名前缀，不重复建库。先读取实时页面、图层、已有批次与数量；不要仅依据旧截图修改。

## Figma 只做整理

本批所有成图通过质检后，导入完整位图并统一排列。每张广告保留一个完整图片节点，外围 frame/section 只用于分类。默认不在 Figma 内设计广告，不新增图片内标题、折扣、CTA、背景、装饰、遮挡或裁切补丁。需要改广告内容时回到 imagegen 修复，再导入新版本。

保留原始宽高比，不为凑网格拉伸图片。统一展示宽度、列数、间距和顶部对齐，横竖比例分别安排；实际像素尺寸单独保留。编号和参考信息位于图片外，不成为导出内容。

主视图按素材类型整理，按实际存在的类型建立分区，不创建空分区：

| 类型示例 | 收纳内容 |
| --- | --- |
| 卖点功能 | 单一功能、功能证明、信息海报 |
| 对比说服 | 新旧方式、有无产品、替代方案 |
| 优惠订阅 | 折扣或订阅利益主导 |
| 生活方式 | 居家、户外、真实使用、生活拼贴 |
| 创意海报 | 巨大标题、杂志、主题场景与视觉概念 |
| 无字视觉 | 约定的 NT 成图 |
| 项目备选/历史 | 用户要求保留但不属于当前方向的旧素材 |

每张图选择一个主要展示类型，生产线/参考来源/批次另作标签，不重复计数。Cozio 的「含猫备选」是项目特有分类，其他项目不能机械照搬。新一批可在原页面增量整理，也可新增清楚标注批次的项目页面并在其内部分类；不移动或覆盖用户已有内容来凑统一结构。

## 可选资料页

以下是完整项目的资料组织建议，按现有结构使用，不要求每次新建所有页面。

| 页面 | 内容 |
| --- | --- |
| 00｜全库总览 | 全部成品缩略图墙，按素材类型分区，可定位母版 |
| 01｜产品与品牌底座 | 图片、角度、颜色、规范、确认参数、证据与视觉配方 |
| 02｜竞品与灵感 | 参考图、来源、读取日期、拆解与借鉴方向 |
| 03｜创意母版 | 完整成品位图、母版与衍生关系、生产线标签和字模式 |
| 04｜待投放 | 质检通过的最终画框、尺寸适配与导出区 |
| 05｜投放结果与迭代 | 表现、观察周期、判断、保留项与下一批假设 |
| 06｜历史归档 | 被替换或淘汰版本与原因，不删除已有内容 |

固定缩略图尺寸与间距，分区标题清楚，不堆叠素材或留下巨大空白。总览与待投放可以复用素材，但只能计一次母版。

编号、来源、卖点、状态与假设放画框外，导出框内只有广告内容，无字版不加装饰编号或水印。

## 编号与版本

示例：`PROJECT-USP-001-M01-v01-1x1-NT`。

- 生产线代码：REF 竞品拆解、CMP 对比、STY 时尚、USP 卖点、WIN 赢家、VIS 纯视觉。
- `001` 为概念序号，`M01` 为母版，`v01` 为修订。尺寸、语言和微调衍生保持母版标识。
- `NT` 完全无叠加文字，`TXT` 含字；语言加入含字版本编号。
- 创意概念明显变化才新增母版；修错、改价和改尺寸只更新版本。
- 记录实际 Figma 节点 ID，重跑先查编号和节点，更新或续做，避免重复。

## 清单字段

在项目工作区保存 JSON 或 CSV 清单，Figma 画框外只保留阅读需要的简短信息。

| 字段 | 内容 |
| --- | --- |
| creative_id / master_id / parent_id | 唯一编号、母版、父版本 |
| category / track / batch / tags | 主素材类型、生产线、批次和其他标签 |
| audience / scenario / selling_point | 受众、场景和主卖点 |
| hypothesis / retained_elements / changed_variable | 假设、保留项和变化 |
| reference_id / reference / claim_evidence | 逐图对应来源、广告编号/链接/日期证据和宣称依据 |
| text_mode / language / width / height | 字模式、语言和尺寸 |
| asset_path / prompt_path / sha256 | 最终成图、完整提示词和文件校验值 |
| figma_page_id / figma_node_id / figma_category_frame_id | 实际页面、图片节点和分类容器节点 |
| status / qa_notes | 草稿、已质检、待投放、已投放、归档及检查结果 |
| evidence_level / metrics_period / ad_id | 探索、候选或验证、观察周期、广告关联 |

未取得的数据留空并标明，不虚填。有数据后记录与目标相关的花费、曝光、点击、转化、CPA 或 ROAS。

## 视觉配方与恢复

记录当前产品适合的风格、背景、构图、灯光、真实角度、文案/无字规则、失败模式与有依据的有效元素。只作用于当前项目，不推广成所有品牌的审美模板。

核验清单计数及 Figma 实际节点与画面；导入回执或本地文件存在不能代替可见检查。

逐类回读实际子图片数量，与清单、约定参考范围和生成文件数交叉核对；重复展示、修订、参考图、联系表和容器不能计为新增广告。查看总览和代表性大图，等待图片纹理加载清晰后验收，不能用模糊预览判断完成。

交付可附按相同素材类型建目录的 ZIP，包含成品、提示词、清单和参考索引。研究证据另放目录，不能混入可投放图片目录。检查压缩包完整性、成品数量与文件校验值；本地 ZIP 不替代指定的 Figma 交付。

中断时保存已完成母版、资产、节点 ID、剩余配额与检查点。恢复后读取记录和实时 Figma 结构，从缺口续做。缺少截图能力或写入能力时标记未验证或未入库，不声称完成。
