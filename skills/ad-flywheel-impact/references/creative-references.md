# 逐图参考与公开广告资料库

## 用户指定范例

1. 用实际可用工具打开指定 Figma 文件和目标 frame，检查完整范围，不只看首屏或缩略图。
2. 盘点每张完整广告，记录参考编号、所属 frame/节点、截图或参考路径、比例、主视觉、文字与 CTA 关系。独立徽章、装饰组件和同图重复展示另行标记，不误算成完整广告。
3. 用户说「每一张都参考」时建立逐一对应表：参考编号→新图编号→参考机制→状态。不能抽几个代表替代全量；看不清或无法读取的项标明缺口，不能声称全部覆盖。
4. 范例中的视频只参考可见的静态广告构图并标明来源类型；不要把视频缩略图描述成经过筛选的静态图片广告。
5. 转化品牌、产品、文案和商业条件。不得沿用竞品 Logo、产品、用户肖像、销量、评价、媒体背书、优惠或专有文案。

## Meta Ads Library 长投图片筛选

入口：https://www.facebook.com/ads/library 。通过 ego-browser 查看公开广告库。自有账户后台和效果数据另走官方 Marketing API。

- 明确市场/国家、广告类别、广告主与当前状态；地域默认可用全部地区做创意研究，用户指定市场时遵从。核对官方广告主页，排除同名无关广告主。
- 素材筛选同时考虑「图片」和带文字图片（界面可能称「搞笑图文」或「图片和搞笑图文」）。只选普通图片可能漏掉压字广告。
- 筛选器结果仍须查看实际素材。混合轮播可以提取其中静态图片，记录卡片位置；不能把视频封面当静态图片成品。多版本广告记录本次实际看到的图，不假定所有版本相同。
- 「正在投放」与「所有投放」按用户要求选择；用户二选一皆可时优先当前投放中且起投日期超过一个月的候选。
- **当前投放中**：记录开始日期与实际核查日期。按日历月计算一个月前的截止日期（目标月无对应日取月底），严格早于截止日期才是超过一个月，同时列出实际相隔天数。不要硬把一个月等同 30 天。
- **已停止**：必须获得开始与结束日期，结束日期严格晚于开始日期加一个日历月才纳入；只有旧开始日期不足以证明投放超过一个月。未知结束时间、状态或日期的记录不计入已核验样本。
- 日期筛选器可能是「所选期间有展示」，不等于连续投放时长。广告起止日期也不能证明中间从未暂停，或当前某张轮播卡/版本从第一天就存在；说明这是广告级日期证据，不能夸称该张图片连续投放天数。
- 广告库对地区和已停止商业广告有可见范围限制。查不到不等于从未投放。访问失败时说明实际限制，不用搜索摘要或猜测补齐日期。

## 参考记录与选择

每个选中参考至少记录：

`reference_id、brand/page、ad_library_id、详情链接、国家/市场筛选、状态、开始日期、结束日期（若有）、核查日期、相隔天数、素材类型/轮播卡、截图或图片路径、可借鉴机制、对应新图编号。`

保存日期/状态证据和实际参考图。按视觉去重，不把多个广告 ID 的同一图片当多种创意。选取不同表达机制，达到本批所需覆盖后进入生产；不要为凑数纳入不符合时长的样本。

长投只是研究筛选信号，不代表 CPA/ROAS 好或已验证赢家。没有效果数据统一标「参考/探索」。只有实际取得的自有投放结果才能进入赢家判断。

交付保留可点击详情链接与参考→新图对应表。竞品原图归入研究证据目录，与可投放的自有品牌成品区分，避免误投。
