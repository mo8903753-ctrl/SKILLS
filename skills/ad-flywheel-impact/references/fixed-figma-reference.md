# 固定 Figma 范例库

固定来源：[投广图参考案例](https://www.figma.com/design/hkRhOHVzWHJHgEuBeliAoL/?node-id=0-1)。文件 ID：`hkRhOHVzWHJHgEuBeliAoL`，入口节点 `0:1`。

这是团队默认且固定的广告设计参考库。新项目、续批中涉及 Figma 范例参考的图片均从此库选取；除非用户明确更换，不因项目产品链接、成品交付文件或旧案例中的链接而替换。用户额外提供的美国赢家图、竞品广告、项目范例作为补充来源，分别记录。不是要求每张广告套用同一模板，也不是要求每批照搬全库。

## 制作前必须执行

1. 使用当前可用 Figma 连接器读取；涉及浏览器操作必须用 ego-browser。实际检查页面和相关 Frame 的完整图片、布局与文字层级，不能只读文件名或缩略图便声称参考完成。
2. 按当前市场、语言、素材类型、产品与用户要求挑选适用 Frame，建立参考到新图对应表。完整首轮应包含固定库参考方向；纯局部修订沿用已核验映射，不无端扩批。
3. 每张参考型图片记录 `reference_library_url`、`reference_frame_id`、`reference_frame_url`、`reference_checked_at`、`reference_access_status` 与 `retained_elements`。ID 必须来自真实读取，不能编造。提示词写清采用的构图、层级、留白、标签与 CTA 位置；不能照搬其他品牌的产品、Logo、优惠或宣称。
4. 同版式任务按指定范例维持版式；其余任务分别保留所选 Frame 的差异，避免全部变成同一模板。
5. 无访问权限或无法看清时，记录 blocked/unverified，说明需要该库权限或相关 Frame 导出图。可继续其他独立方向，但固定库参考方向不得标记完成，不用包内 PONGBOT 成图冒充已查看固定库。

## 参考库与交付库分开

此文件只读参考。提供参考链接不授权向它上传成品、创建页面或改动原范例。成品写入项目另行指定的 `figma_target`。没有交付目标时先保留本地交付，并询问目标；不要默认把固定参考库当成成品库。

## 安装包快照范围

链接由用户明确指定并授权随团队包分享。此版本只固化链接和执行规则，未读取、导出或打包该库实际 Frame；接收方须在执行时检查访问能力与实时内容。包内 PONGBOT 示例是另一个历史案例，不能替代此库。
