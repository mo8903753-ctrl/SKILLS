# HTML 商业版设计标准

面向国内品牌方客户的商业级 HTML 提案的设计规范和常见陷阱。

## 设计系统（浅色主题）

参考 Notion + Apple 设计语言：

- **背景色**：`#ffffff`（纯白）+ `#f7f6f4`（暖白）交替分区
- **主色调**：`#2B5CE6`（蓝）+ `#C8A951`（金）双色系统
- **文字色**：`rgba(0,0,0,0.92)` 正文 / `#5E5B55` 副文 / `#9E9A93` 弱文
- **边框**：`rgba(0,0,0,0.08)` 细线
- **字体**：Inter（Google Fonts CDN），标题负 letter-spacing
- **圆角**：14px（卡片）、100px（标签）、16px（大卡片）

## 必须包含的视觉元素

1. **SVG图表**（至少3组）：
   - 竞品定位象限图（2轴散点）
   - Email漏斗对比图（现状 vs 目标）
   - 预算瀑布/条形图

2. **SVG图标**：KPI卡片用语义色图标，不用emoji

3. **动效**：
   - Intersection Observer 滚动渐入（`.reveal` + `.visible`）
   - 卡片 hover 上浮（`translateY(-2px)`）
   - Hero 区域浮动光球（`@keyframes float`）
   - KPI 数字递增动画（`animateValue`）

4. **导航**：固定毛玻璃顶栏（`backdrop-filter: blur(20px)`）+ 锚点高亮

## 内容完整性原则

- 即使用户提供的框架只有 6-8 个章节，也必须把 Skill 的 12 个模块全部穿插进去，不能遗漏
- 不要为美观缩略内容——美观和内容可以共存

## 常见陷阱

- **深色背景**：国内客户不习惯深色提案页，默认用浅色
- **emoji过多**：用SVG图标替代emoji
- **缺少SVG图表**：纯表格不够商业级，必须配图表
- **内容缩水**：不要为了"简洁设计"删减策略模块
- **日文泛滥**：参照Skill语言规则，默认全中文
