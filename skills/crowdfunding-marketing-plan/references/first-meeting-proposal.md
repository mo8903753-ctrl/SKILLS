# 首面提案（First Meeting Proposal）

面向品牌方总负责人（Big Boss）的首次线上会议提案，与完整众筹方案（29页）在结构和目的上有本质区别。

## 核心区别

| 维度 | 首面提案 | 完整众筹方案 |
|------|---------|------------|
| 页数 | 10-12 页 | 24-29 页 |
| 目的 | 让对方在30分钟内相信3件事 | 展示完整执行路径和KPI模型 |
| 重点 | 战略判断 + 市场洞察 + 方法论 | 执行细节 + 预算 + KPI + 排期 |
| 公司介绍 | 1页或附录，轻量背书 | 可独立成章节 |
| 预算表 | 不需要 | 必须有（双档切换） |

## 黄金四步结构

基于用户实际验证的高转化首面提案框架：

1. **核心判断（1页）** — 接住品牌方最大疑虑，给出正面回答。不是"我们公司很厉害"，而是"我懂你的产品在市场上遇到了什么问题"。

2. **市场洞察（2-4页）** — 用数据和案例证明"我比你更懂这个市场"。包括本地化洞察、竞品分析、用户画像。

3. **方法论展示（2-3页）** — 不炫耀案例本身，而是拆解操盘逻辑。用对比表展示"传统做法 vs 我们的做法"。

4. **路线图 + 下一步（2-3页）** — 给Boss安全感：有节奏、有控制、有止损机制。以明确CTA收口。

## 内容风格要求

- 全程中文为主（面向国内品牌方客户）
- 专业但不官腔：每句话都要能念出来像人话
- 不做功能复述：品牌方比你更懂自己的产品
- 不做公司自嗨：第一页不堆资质和案例墙
- 竞品对标要有实质分析：不只是"你看竞品卖了多少钱"

## 流程

用户通常先要求出文字内容确认，确认后再做 HTML/PPT。不要跳过内容审阅直接出设计稿。

## 设计

- 配色：Patagonia 暖土色系（charcoal/stone/clay/sand/cream + accent #C8734A + teal #3D6B66）
- 浅色背景为主，深色仅用于封面和关键概念页
- SVG 图表内嵌，不依赖外部资源
- 零外部依赖（字体用系统栈）
