# 第三方众筹社区列表（固定资料库）

本文件为固定数据，每个项目通用，不需要修改。

## 社区合作核心逻辑

核心：买流量邮件位 → 导流到 KS → 转化下单
优先选择：Top位 + 专属信
节奏：分批打 + 看ROI复投
目标：用 $10K 撬动 $80K+ 回报

## ROI 判断标准
- ≥2.5：可复投
- ≥3：重点加码
- <1：联系补发/停止投放

## 投放节奏

| 阶段 | 策略 |
|------|------|
| 上线前3天 | 不投（避免浪费） |
| 上线0-3天 | 集中投放第一轮推荐的8家 |
| 中期（Day 4-15） | 分批投放共24家 |
| 尾期（Last 5 days） | 再投4-5个表现好的Dedicated newsletter |

## 备注
1. 支持使用 Credit Card 和 PayPal 进行支付
2. newsletter的普通位置很难吸引到用户，所以推荐 top spot 或者专属 newsletter
3. 部分需要佣金的第三方会员社区在项目结束前会扣除佣金，建议使用没有额度的信用卡
