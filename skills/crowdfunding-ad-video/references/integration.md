# 与图片飞轮合并使用

## 共同事实，独立制作
与图片共用品牌原素材、市场、语言、活动阶段、优惠限定和文案来源；历史样例不是当前价格事实。平台 Logo 文件来自用户上传技能包，此次未重新访问官方站点验证，执行时核对适用品牌规范。不同镜头机型不得混装；原视频人物/场景可裁切调色，不生成补造。

## 依赖与可移植性
Python 3、ffmpeg/ffprobe、Pillow；抠图需要 numpy/scipy，语音转写需要 faster-whisper 和实际模型文件。检查工具和字体后再渲染。默认字体为 macOS 字体；其他系统必须在 project.json 的 fonts 中指定存在且支持目标语言的字体及索引，禁止缺字仍交付。inspect_source.py 的联系表字体通过 ADKIT_INSPECT_FONT 指定。

有语音必须听/转写原片与输出并确认断句，不可只看联系表就宣称完整审片。无模型先报告未完成音频检查；无语音素材走音乐/叠字路径，不虚构转写。模型下载脚本仅在确需且符合宿主规则时执行；不能因为安装技能便自动下载大模型。

本技能的源 JSON 是历史配置，时间点/素材/35% 等必须全量重建。只需要叠字的客户成片保留原时长；TVC 可剪长版约60–95秒和20–25秒单卖点短版。源片不足时不强拼时长，不循环填充冒充新创意。优先场景、前三秒见产品、首帧叠层完整、同屏折扣不重复、人物和原字幕不遮挡。

## 统一交付
MP4 与图片分开目录、独立计数。同一剪辑的画幅/语言版本是衍生，不重复算母版。保存 project.json、逐句文案来源、原片/入出时间/裁切/音轨/字幕记录、输出哈希、时长、尺寸、QA状态。联系表/海报/抽帧不能充当投广视频。播放并听完整成片，查看首帧、前三秒、转场与结尾；参数检测不等于视觉或音频验收。

视频 ZIP 使用经过验证的最终目录，不混入旧版或缓存。视频在 Figma 中只放封面与实际成片链接（如环境允许）；封面不能算视频交付。没有可用托管权限时交付真实本地 MP4/ZIP，不虚构在线地址。清理仅限缓存，保留源文件、脚本及 project.json。
