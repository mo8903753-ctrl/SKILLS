# Crowdfunding EDM Image Templates

These are fallback stage templates only. If the user provides a Google Sheet row, MailerLite/Klaviyo draft, pasted template, or existing EDM skill/template, that external template is canonical. Use the external template's exact wording and replace variables only.

Variable syntax: `{{variable_name}}`.

## Deposit Invitation

- Stage goal: get pre-launch users to place a refundable deposit.
- Subject: `Deposit x Saving Event is Here - Grab {{product_name}} Best Offer`
- Preview: `Place {{deposit_amount}} deposit and secure {{deposit_benefit}} before the official launch.`
- Headline: `Deposit x Saving Event is Here`
- CTA: `Place {{deposit_amount}} Refundable Deposit`
- URL: `{{deposit_url}}`
- Body: `Dear {{audience_name}}, thanks for signing up for the {{product_name}} campaign! The team is excited to announce a limited-time VIP deposit offer for {{product_name}}. For a short period, you can secure your spot before the official launch with a {{deposit_amount}} refundable deposit and unlock {{deposit_benefit}}. {{product_positioning}} See you at the official launch!`
- Image direction: premium product hero, savings mood, clean studio or light lifestyle scene.
- Layout note: place this body copy in a solid black or white panel for readability. Do not overlay paragraph copy directly on a busy product image.
